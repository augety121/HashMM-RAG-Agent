# HashMM App V282

日期：2026-07-19

- 首页 Chat 和详情 Chat 接入与桌面端相同的服务端消息反馈链路，不再只有视觉上的点赞/点踩。
- 点踩必须选择事实错误、证据不足、检索遗漏、工具错误、任务未完成、指令偏离、安全风险、响应过慢或其他，可补充具体说明。
- App 只提交评分、失败分类和说明；问题、答案、来源、工具调用与运行轨迹由 backend V349 从属主校验后的服务端消息中读取，客户端不能伪造评测样本。
- 提交后刷新同一会话消息，使 App 与桌面端显示同一个权威反馈状态。
- 手机直连模型没有服务端运行轨迹，反馈入口有意隐藏，避免把本地演示数据伪装成已进入评测闭环。
- 负反馈只进入人工待复核队列，失败答案不会自动成为标准答案；管理员填写可信参考答案后才进入 held-out 回归集。
- 新增反馈分类和未知分类回退测试；版本升级为 versionCode 98、versionName 1.10.57。
