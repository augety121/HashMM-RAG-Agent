# App V262 —— 远程虚拟鼠标 UU 化重做（五连修） · 「后端未启动」状态卡

## ① 远程虚拟鼠标：对照 UU 逐项重做（你实测的五个问题全部对上根因）
交互模型整个换掉——**部件位置是唯一真相**（tip = 箭头尖端屏幕坐标，官方
draggable 模式）。旧实现"本体位置由光标反推、拖本体又去改光标"的自跟随反馈环，
正是"拖不动 / 被锁死一角"的机制根源，这次连根拆掉：
1. **小鼠标移不动** → 根因：它是纯装饰 Canvas，没有任何手势。按你的要求删除，
   UU 就是"箭头 + 本体"一体，没有第二只鼠标。
2. **大鼠标只能在右下 1/4 移动** → 反馈环 + 视口跟随叠加所致；现在拖部件任意
   区域 = tip 直接加手指位移、全屏 clamp，四角可达。
3. **箭头被压在左键下面** → 箭头固定画在部件容器左上角（尖端=容器原点=真实
   落点），本体永远在箭头右下 18/22dp——任何机型密度下箭头都在左键上方外侧。
4. **左右键有按压动画但点击没用** → 点击本身走 0..1000 归一坐标链路（App→信令→
   桌面协议校验→CU 驱动注入，链路已核验健全），"没用"是光标机制卡死导致点在
   错误落点；机制重做后左右键 tap 即在尖端真实落点发送点击。
5. **拖动屏幕大鼠标乱跑** → 旧"单指拖=1.8 倍增益移光标+视口跟随"删除：现在
   放大后单指拖=**平移画面**（部件钉在内容点上，跟着内容走、绝不乱窜），未放大
   =1:1 触控板移光标；双指缩放/平移原样。另新增 **点哪打哪**：触控板模式下点
   视频任意处=落点传送过去并左键（双击/长按=双击/右键），比"先挪再点"直觉。
滚轮 ▲▼、拖动键（按住拖=实时拖动 / 单击=粘滞拖选）、✕ 收起、收起态圆钮全部
保留，位置与手势跟随新部件。
