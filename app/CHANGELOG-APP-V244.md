## ② 「动态」整页重构（ui/activity/ActivityScreen.kt 重写）
给这一页一个真正的"信息流"身份，五层信息架构：
1. **今日简报**升级为米色英雄卡：眉题 + **电脑端在线小胶囊**（原「电脑端与定时任务」整段分区退役、收进这里）+ 一句话正文 + 看轨迹/看定时链接 + **近 7 天用量脚注**（原独立三格用量卡并入，页面少一张仪表卡）。
2. 快捷指挥四格（白卡 + 回弹 + 派活弹窗，保留）。
3. 「进行中」：正在生成 + 后台任务合并为一个分区。
4. 「最新产物」：从"每个文件一张卡"收进**一张分组白卡**（38dp 徽章：html=米色「画布」/其余灰底扩展名，行间发丝线，行内标准涟漪）。
5. **「系统时间线」（新主角）**：运行轨迹 / 定时任务 / 经验学习三路事件按时间合并成一条带**轨道线 + 状态点**的竖向时间线（失败=围巾红、完成=绿、执行中=琥珀、学习/中性=灰），"系统在替你干什么"一眼读完。
- 通知条 / 后端状态条 / 下拉刷新 / 实时订阅逻辑不变。

## ③ 任务落地页（电脑任务 4 卡 + 对话任务 2 卡点进去的会话页）
- 由"电脑任务/取文件"发起的会话：顶栏标题直接显示**「电脑任务」**（生成中带后缀），标题下挂一条**米色任务横幅**「桌面端任务会话 · 执行结果会回传到这里」——点完卡片能立刻确认这是任务会话。
- 底部任务下发历史条 Marvis 化：标签改「桌面端」，去描边小卡 → 白色圆胶囊。
- 实现：ChatDetailViewModel 暴露 `isDispatchSession`（派发逻辑零改动）。

## ④ 系统动态 5 页（定时 / 轨迹 / 审计 / 质量 / 高级）
- **NativeUiKit 分组化**：新增 `KitGroup`（分组白卡）+ `KitInsetDivider`（发丝线）；`KitRow` / `MetricRow` 从"每行一张卡"改为组内行——四个列表页从碎卡墙变成一张干净的分组卡。
- 审计页筛选 chips（时间窗 + 工具）：选中＝**墨黑实心 + 白字**（Marvis 分类 chip），未选中＝白底灰字。
- 高级能力页：灰底功能卡 → 无边白卡 + 裸墨黑图标；散落的 TextButton 全部换成**浅灰操作胶囊**（FlowRow 自动换行，窄屏不挤爆）；最近任务收进分组卡。

- **知识库**：概览卡去描边；当前模型 chip 改**米色**（AI 语气）；文档列表收进分组白卡（裸墨黑文档图标）；"已索引文档 N"改灰色小字分区标签。
