# HashMM App V199 变更说明

基线：V198。本轮聚焦工作台（Workbench Hub）的信息架构与视觉重构，配套客户端 V205（新增高级能力）。功能链路不变，只重排版式、对齐大厂 App 标准。

## 1. 工作台整体重构（WorkbenchHubScreen.kt）

- 现象：原工作台是一长条卡片流——大号 Hero（92dp 吉祥物 + 25sp 大标题）占屏过多，"电脑任务/对话任务/客户端能力"混在同一列纵向堆叠，扫视成本高，字号偏大不像专业工具。
- 改法：改为对标大厂 App 的三段式信息架构。
  - **① 顶部品牌区**：吉祥物缩到 44dp，标题降到 22sp，左标题 + 右侧「在线状态胶囊」横向排布（绿点在线/灰点离线/转圈探测中，点击刷新），像工具台而非落地页。
  - **② 任务区**：电脑任务（交给桌面端执行）与对话任务（直接问 Agent）各成一组，每条为紧凑单行卡（图标淡染主色底 + 主副标题 + 右侧统一箭头）；电脑任务在离线时整卡降透明并禁点，并给出"先接力唤起桌面端"提示。
  - **③ 能力区**：知识库/记忆中心/模型后端/知识图谱/管理后台/用量/失效区改为两列网格小卡（图标在上、标题在下），同级能力并置，比原长列表更易扫读。
- **字号梯度对齐大厂**：section 标题 13sp / 卡片标题 15sp / 副标题 12.5sp / 辅助说明 11.5sp，去掉原来的装饰性大字号。
- **接力卡**上移到任务区之前（工作台里最高频的跨设备动作），主色整条卡 + 图标容器。

## 2. 保持不变（本版不动）

- 任务下发链路：点击任务 → `onRunComputerTask(text, kind)` / `onRunTask(text)` → 新建会话并按 kind 下发到桌面端，结果回对话。与客户端能力联动逻辑一致。
- App 图标资源、其余页面（对话/远程/我的等）本版未改，列入后续轮次。
