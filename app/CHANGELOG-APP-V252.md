# App V252 —— 虚拟大鼠标重设计 + 放大后全屏可达

## ① 虚拟大鼠标（对照 UU 远程浅色大鼠标样式全新重画）
展开态从 116×134 的深色小块升级为 **172×212 浅色大鼠标**，五键一板、全部可点、互不冲突：

```
┌───────────────┐
│ 左键 │▲滚▼│ 右键 │   顶部三分：左键 / 滚轮胶囊（上滚·下滚两个可点半区）/ 右键
│    ［拖动键］    │   腰部胶囊：点一下=定拖选起点，再点=完成（框选/拖窗/拖文件通吃）
│               │
│   移动触控板    │   底部大区域：手指拖动 = 移动光标（增量）
└───────────────┘
```
- **左键**：点=单击；拖选中点=完成拖选；长按=取消/定起点（兼容旧手势）。
- **右键**：点=右键菜单。
- **滚轮 ▲▼**：两个独立可点半区，上滚/下滚。
- **拖动键**（腰部胶囊）：显式的拖选开关——点一下定起点（胶囊变主题色"拖动中…"），
  移动光标到目标，再点一下完成。与"长按左键"同一状态机，入口更显眼。
- **移动触控板**（底部）：在板上拖动=增量移光标——不用再必须到屏幕上拖。
- 左上角 ⠿ 把手拖动=挪整个鼠标窗；右上角 ✕ 收起成小圆钮（可拖动、点击展开）。

## ② 放大后光标可达整个远程屏幕（"页面外的看不见大框"）
旧行为：放大后单指拖=平移画面，光标被**困在当前可视框里**，屏幕外的东西够不着。
V252 起：
- 单指拖（屏幕或触控板）**始终移动光标**，光标坐标覆盖整个远程屏幕（0..1 内容坐标）。
- **视口自动跟随**：光标的屏幕投影一旦贴近可视边缘，画面自动平移把光标追回视野内
  ——光标带着视口走，放大只是"放大镜"，可达范围不缩水。
- 放大时移动量按缩放比补偿：手指移 1cm，光标在**看到的画面里**也约移 1cm，精细操作更稳。
- 想纯平移画面（不动光标）：双指拖，原手势不变；双指捏合缩放不变。
