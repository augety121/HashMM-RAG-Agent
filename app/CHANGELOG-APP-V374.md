# HashMM App V374 — 原生长任务控制与断线防重放

## 统一控制协议

- App 的“运行轨迹”不再只显示服务器状态。页面直接读取 `hashmm.work-control.v1`，只为当前运行展示后端实际支持的暂停、从检查点继续、停止或重新派发。
- 每次操作携带命令 UUID 和运行 revision。服务器已经变化时，App 会要求刷新，不用旧页面覆盖新状态。
- 操作成功后将服务器返回的运行与事件写回账号隔离的加密缓存，并强制重新校验明细 ETag。

## 真实副作用边界

- 长任务是检查点式协作暂停；多 Agent 是等待当前模型调用返回后停止；App 会在详情中明确显示这种区别。
- Browser Use、Computer Use 与取文件任务只能在桌面端领取前取消。已领取时显示真实冲突，不伪装成撤回成功。
- 多 Agent 重试创建新的关联运行，旧任务保留作为审计记录。

## 断线与恢复

- 控制请求发生网络歧义时 App 不自动生成新命令重放，避免同一个外部操作执行两次。
- 服务端长期未确认的命令显示为“结果待确认”，用户先刷新和核对任务，再决定下一步。
- Android App 版本更新为 1.10.77（versionCode 118），对应 Backend V374。
