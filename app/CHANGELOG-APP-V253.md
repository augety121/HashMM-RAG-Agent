# App V253 —— UU 式虚拟大鼠标（交互模型重构）

## 完全对照 UU 远程重画 + 重构交互模型
**核心变化：鼠标本体 = 光标本身。** 白色箭头"挂"在本体左上角，箭头尖端即点击落点——
所见即所点，这就是 UU 的"左上角鼠标箭头"。

### 外观（对照图2）
- 150×190 竖长圆润本体，浅蓝白渐变 + 灰蓝描边，**无任何文字**（旧版"左键/右键/拖动/
  移动"标签全部去掉）。
- 顶中**滚轮胶囊**（白底描边，▲▼ 实心三角两可点半区：上滚/下滚）。
- 滚轮下方**拖动键胶囊**（UU 同款"两横线"图标）。
- 上半左右分区 = 左键 / 右键（tap 即点击）；下半掌托留白。
- 右上 ✕ 深色圆钮收起 → 右下角小鼠标圆钮（可拖挪、点击展开，展开后本体自动吸附回光标处）。

### 交互（三处按反馈重做）
1. **拖动键可以"点击（按住移动）进行拖动"了**：按住拖动键不放直接拖手指 =
   实时拖动（按下记起点 → 拖动移光标 → 松手自动发送拖拽）；单击 = 粘滞拖选开关
   （点亮 → 自由移光标 → 点左键或再点此键完成）。两种习惯都支持。
2. **移动方式统一**：拖本体任何区域（左右键面上滑动、掌托）= 移光标；在屏幕空白处
   单指拖 = 移光标（本体自动吸附跟去）。放大时移动量按缩放比补偿，精细操作稳。
3. **边缘可点**：箭头尖端可达屏幕四个角（本体允许部分移出屏幕）——"鼠标往屏幕边缘
   移动时不方便点击"从根上解决。放大后想看/点别处：双指平移画面，再把鼠标拖过去——
   分工明确，无落点漂移（因此移除了 V252 的"视口自动跟随"，它与"本体=光标"模型冲突）。

### 实现说明
- 本体锚定在光标屏幕投影处（`offset(axT+12, ayT+16)`），与内容层白箭头共用同一套
  contentRect + 缩放/平移变换数学——箭头指哪、点击就落哪，适应/铺满/放大全场景一致。
- `moveTip(dx,dy)`：尖端屏幕位移 → clamp 全屏 → 逆变换回内容归一化坐标 → 上报；
  手势闭包内每次现算（读最新 state），杜绝组合期快照造成的漂移。
- 旧 FloatingMouse（挪窗式、带文字）整体删除；代码净减 ~2KB。
- versionCode 67→68，versionName 1.10.26→1.10.27。静态自查：括号/引号平衡通过。
