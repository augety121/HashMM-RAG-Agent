# App V254 —— 虚拟大鼠标：联动、缩小、按压反馈、光标对齐

按实测截图逐条修：

1. **小鼠标 ↔ 大鼠标联动**：收起后的小鼠标钮不再固定在右下角，而是**贴着箭头一起走**；
   点它=原地展开成大鼠标，在它上面拖=照样移光标。小↔大只是形态切换，位置始终跟着箭头
   （UU 同款心智）。
2. **本体缩小**：150×190 → 116×148，滚轮/拖动键/圆角等比缩小，不再遮挡视野。
3. **左右键按压反馈**：按下即高亮浅蓝，松开恢复——点没点到一眼可见。
4. **箭头与大鼠标一体**：本体锚定偏移加大（+30,+42px），完整的白箭头露在本体左上外侧、
   尖端即落点；**进入触控板模式先把被控端光标对齐到 App 光标处**（此前 Windows 真实光标
   停在别处，看起来像"箭头和大鼠标是分开的"——实为两枚光标未同步，现已进场即对齐，
   之后每次移动都同步，视觉上始终只有一枚箭头挂在鼠标左上角）。
