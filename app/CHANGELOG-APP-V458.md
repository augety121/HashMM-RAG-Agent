# HashMM App V458

- App 定位为移动指挥与接力端：读取与桌面端相同的 `hashmm.work-projection.v2`，展示目标、位置、能力路线、Work Map、协作和自治级别。
- 工作运行使用带 Bearer 请求头的 SSE 增量同步，断线从游标恢复；60 秒轮询仅作为修复通道，访问令牌不会进入 URL。
- 工作画布支持针对指定 ArtifactRevision 的页、幻灯片或区域提出修改要求，并显示服务器已确认的批注。
- 断网或请求结果不确定时，批注以稳定 ID 和幂等键进入账号隔离的加密 outbox；恢复网络后核对重放，避免重复副作用。
- 恢复入口区分会话、文件版本和执行检查点；没有真实检查点时不会显示为可以恢复。
- 版本升级为 1.17.0（versionCode 134），对应 Backend V458。

真实公网多设备、对称 NAT、自有 TURN、24 小时稳定性和 Android 正式签名仍需部署环境验收。
