# HashMM App 1.10.85（126）

日期：2026-07-23

- 底部导航收束为“对话 / 待办 / 工作 / 我的”。手机端负责确认、补充、验收和接力，不复制桌面端的开发者控制台。
- “待办”读取与桌面端同源的 WorkRuntime 展示投影，只显示真正需要用户处理的授权、问题、阻塞和交付物；不再展示 revision、event cursor 等内部字段。
- “待办”停止预取旧动态页的用量、Feed、能力与实时活动，减少无关请求和局部接口失败噪声；服务器未验证成功时明确提示，不把读取失败显示成“暂无待办”。
- “工作”使用服务端生成的用户标题、状态和当前步骤，保留真实暂停、继续、重试与对话接力入口。
- 修复内存工作缓存未绑定账号的问题。切换账号时先清空内存快照，再读取当前账号的加密持久化缓存或服务器增量，避免跨账号短时串数据。
- Android 单元测试、Kotlin 编译、Debug/Release 构建结果与 APK 哈希记录在主仓库 `本轮说明-V395.md`。

说明：Debug APK 仅用于验收测试；正式上架仍必须使用产品发布密钥签名 Release APK。
