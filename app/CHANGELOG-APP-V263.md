# App V263 —— 远程虚拟鼠标二次重构（视频实锤 → 根层手势根治）

对你录屏逐帧诊断（f05 帧实锤部件吸死右下角、本体大半出屏）后确认：V262 把拖动
手势放在"会跟着自己移动的部件"上，**手势坐标系自指**——漂移/锁死一角/半屏这一类
问题全是它的不同表现。本次改为教科书稳法，从构造上让这类 bug 不可能发生：

1. **手势全部收在静止的根层**：down 时对部件各区（左键/右键/滚轮▲▼/✕/本体/收起
   圆钮）做命中测试；tip(落点)=手指绝对位置−抓取偏移。坐标系永不移动。
2. **无箭头（UU 式）**：部件不再画箭头——落点在本体顶边中点上方 8dp，被控端
   **真实光标**就是指针反馈（之前"光标不跟/右键没用"多为光标被机制卡死在角落、
   点在任务栏死角所致；机制重做后消失）。
3. **原生按住拖选**：左键按住 ≥350ms 直接发 `left_mouse_down`，拖动实时
   mouse_move，抬起发 `left_mouse_up`——文字选中、拖拽窗口都是系统原生行为；
   短按=单击。旧"粘滞拖选/拖动键/橡皮筋"整套删除（原生方案覆盖且更直觉）。
4. **落点夹取到"变换后的内容区"**：放大/平移下也永远指在远程画面上（治半屏与
   出界）；本体缩小到 96×124dp，部件渲染层零手势、纯视觉，高亮由手势状态驱动。

注意：需用本版本**重新构建 APK**（Android Studio 直接 Run 即可）；被控端桌面
照常。versionCode 77→78，versionName 1.10.36→1.10.37。
