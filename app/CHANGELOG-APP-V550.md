# HashMM App V550

版本：1.21.0（138）  
日期：2026-07-26

## 移动端定位

App 是 HashMM 工作系统的移动控制面：查看今天的工作、处理等待确认、继续同账号任务、查看成果并连接桌面设备。需要本机文件、浏览器、终端或 Computer Use 的执行仍由桌面端完成。

## 本轮变化

- 工作台优先读取 `hashmm.workspace.v2`，与桌面端使用同一 WorkRuntime 事实源。
- 实时同步优先订阅 Workspace v2 SSE；Bearer 令牌只放在请求头，不进入 URL。
- 只有服务器明确返回 404 时才回退旧 Work Feed；网络、鉴权、schema 或信任错误不会被伪装为兼容成功。
- 统一状态映射到原生页面；未知提供方状态显示受阻，历史 `observed` 保持历史记录，不会显示成已完成。
- 待处理事项、成果、证据数量和可用命令从服务端投影；App 不创建演示任务。
- 工作快照继续保存在账号隔离的加密 LocalStore；ETag 未变化时复用缓存，断线时明确显示最近同步结果。
- 底部一级入口使用“今天”，工作台文案聚焦继续工作、阻塞与交付，不复制桌面诊断控制台。
