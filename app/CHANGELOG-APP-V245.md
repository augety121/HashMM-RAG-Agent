# HashMM App V245 —— 管理员识别根因修复（配桌面端 V249 补丁）· 审计/高级能力/图谱/简报/弹窗二轮打磨

## ⓪ 定时任务"要管理员账号"的根因（功能修复，在桌面端补丁里）
不是 App 的锅：后端 `_verify_remote()`（Supabase token 远程兜底校验，旧版 HS256 项目必走）把
`app_metadata`/`user_metadata` 整个丢了，而且 admin 判定不认 Supabase 仪表盘里能直接编辑的
`user_metadata.role`。桌面端走密码登录拿完整 user 对象所以没事，App 走 Bearer token 就被降级。
→ **随包附「HashMM-桌面端补丁-V249-管理员识别.zip」**（单文件 supabase_auth.py + diff + 说明），
解压覆盖源码根后按原方式 installer-native 重打包即可；不想改代码也可在电脑端
「设置 · Supabase 管理员邮箱」里加入你的邮箱。App 侧把定时任务的两处提示改成了上述可行动文案。
