# HashMM App V296

## 持续任务真实接线

- “工作总览”把任务目标与完成标准分开输入，完成标准真实发送到后端验收器，不再只是一句界面提示。
- 每次任务可独立选择只读或写工作区、是否联网、是否按需派生专员；选择会随服务器任务持久化。
- 任务列表展示服务器实际返回的联网范围、子 Agent 状态、工具数量和完成标准，手机端不维护另一套演示状态。

## 安全与跨端

- App 与桌面端共用 `hashmm.execution-scope.v1`；子 Agent 只能继承更窄的权限范围。
- 默认不联网、单 Agent、只读。开启写入或联网仅影响本次任务，不改变账号全局配置。
- 任务仍由服务器执行，App 负责启动、查看与停止；离线时不会把本地卡片冒充正在运行的任务。
