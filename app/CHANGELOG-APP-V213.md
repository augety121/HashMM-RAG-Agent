# App V213 — 动态页脱胎换骨 · 紧凑导航 · 工作台补链

对接后端 V218+（/api/feed、/api/health release）。**未经 Android Studio 编译**（本环境无 SDK/Gradle 仓库），
六文件均过括号/引号平衡校验、逐 API 对照既有代码范式手写；以你本机 Gradle 构建为最终验证，
报红按 patches/ 单文件回退互不牵连。

## 动态页（用户点名"只有 token"→ 完整动态流）
- 新增 `data/remote/FeedRepository.kt`：GET /api/feed，防御式解析（时间戳秒/毫秒自适应、
  runner/定时任务字段软取），404 → 明确"后端过旧"错误；产物直接拼好 /view?token= 预览地址。
- `ActivityViewModel`：三路数据（Supabase 实时 + 用量 + feed）并发拉取，暴露 refreshing 供下拉刷新。
- `ActivityScreen` 重写（235→451 行）：下拉刷新（M3 PullToRefreshBox）；分区=后端状态条（过旧
  给升级提示而非留白）/ 用量卡 / 正在生成 / 后台任务 / **最新产物**（.html 标"画布"、点击
  InAppFileViewer 就地预览，其余 ext 徽章）/ 最近对话 / 电脑端与定时任务 / 系统学到了什么；
  相对时间与文件大小格式化；空态文案更新。

## 底部导航（"四个 tab 有点大"）
- `MainScaffold`：M3 NavigationBar（80dp 固定、不可调）→ 自绘 CompactNavBar：**58dp** 高 +
  正确的 navigationBars inset 处理、图标 22dp、文字 10.5sp、选中主色填充图标。四 tab 不变。

## 工作台
- `WorkbenchHubScreen`：**修复孤儿入口**——onOpenWebClient 一直传入却从未被用，App 里没有任何
  按钮能进完整客户端；能力网格补「完整客户端 · 画布/全部面板」卡（画布三入口在里面）。
- `WorkbenchScreen`（WebView）：主帧加载失败 → 全屏错误态 + 重试（原来白屏）；居中大圈改
  顶部细进度条（不挡内容）；头部加显式刷新按钮；返回键既有处理保留。

## 应用
Android Studio 打开本目录直接构建；`patches/*.v212-to-v213.diff` 为逐文件回退，
FeedRepository 为纯新增（删除即回退）。需后端 ≥V218（动态页会自检并提示）。
