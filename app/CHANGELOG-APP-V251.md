# HashMM App V251 —— 执行体切换上首页（主链路补齐）· 配套桌面 V253

## 为什么你在 App 里"看不到"
上一版的直连兜底与执行体切换只接在「会话详情页」——而你日常聊天用的是**对话首页**
（它有独立的发送链 ChatHomeViewModel），主路径上功能整个缺席。本版补齐主链路。

## 本版内容
- **首页顶栏执行体切换**（Marvis「我的手机 / Augety」同款）：HashMM 标题下
  状态点 + 执行体名 + 箭头，点开三档：自动（推荐）/ 桌面端·后端 / 我的手机·直连；
  直连＝围巾红点、桌面端＝绿点。
- **全局持久**：执行体存 SettingsStore，首页与会话详情页共用同一值、重启不丢。
- **首页发送链接入直连**：direct 档跳过后端直发；auto 档后端两级失败自动兜底；
  backend 档不兜底并给明确文案。直连轮次（问+答）upsert 入 Supabase 会话——桌面可接力。
- 首页新增米色「直连模式」横幅；后端恢复自动清除。
- 修复 ChatHomeUiState 双逗号编译错误。
