# HashMM App 1.11.0（127）/ Backend V400

## 用户工作流

- 新增长任务原生工作画布，按“概览 / 过程 / 依据 / 成果”展示同一服务端 WorkRuntime。
- 活动页和工作台中的真实工作可进入同一详情，不再打开桌面诊断页或重复页面。
- 可查看真实阶段、分支、检查点、来源、检查回执、失效原因和交付物。
- 文档、PPT、表格、PDF、图片、画布与代码成果继续交给 App 内文件查看器或系统应用。

## 验收与恢复

- 支持带修订号的接受成果和要求修改；要求修改必须填写说明。
- 支持服务端实际发布的暂停、继续、取消与重试动作。
- 展示完成可信度和限制，用户接受限制不再显示成自动核验通过。
- 受治理建议不会自动执行，也不会从手机端扩大桌面权限。

## 同步与缓存

- 使用账号隔离加密缓存和 ETag 增量校验。
- 同账号桌面端与 App 读取相同运行 ID、修订号和事件事实。
- 动作成功后只失效对应运行快照；离线只展示最后一次验证通过的数据。
- 切换账号时清除内存投影，避免不同账号串数据。

## 技能与证据

- 依据层只展示本次实际使用的技能 ID 与精确版本。
- 不显示技能私有提示正文。
- 不把一次运行或一次接受解释为技能自动进化；技能发布仍由独立回放和安全门控制。
