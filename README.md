# HashMM

面向资料研究和项目工作的 RAG + Agent 工作空间。

[使用 HashMM](https://hashmm.hashlens.org/) · [服务状态](https://hashlens.org/hashmm/status) · [反馈问题](https://github.com/augety121/HashMM-RAG-Agent/issues) · [参与协作](COMMUNITY.md)

本仓库用于产品说明、问题反馈和公共协作 PR。当前产品源码在私有仓库维护，不随公共 PR 发布。

## 如何参与

提交可复现的问题、文档修正或功能建议。不要上传私有资料、账号信息、原始日志、内部源码或安装载荷。

## 验证

公共文档检查与维护者触发的私有产品验证分别记录。私有验证只针对指定提交执行，结果回写对应私有提交；公开日志不展示原始测试输出。详见 [维护说明](MAINTAINERS.md)。

## 历史内容

本轮从当前文件树移除历史实现目录，但已有 Git 历史、旧分支、标签或下载副本不因此消失。历史许可保持不变，不能将此变更视为历史代码已撤回。
