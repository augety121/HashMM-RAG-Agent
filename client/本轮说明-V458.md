# HashMM V458 本轮说明

V439–V458 不是再增加一组孤立功能页，而是把 Chat、长任务、项目、成果、跨设备接力和多智能体统一到一份服务端事实投影 `hashmm.work-projection.v2`。桌面端负责本地执行与深度编辑，Android App 负责查看、批注、授权、接力和恢复；两端不各自猜测任务状态。

## 已完成

- V439：明确 Chat、Work、Project、Artifact 四类对象边界。普通问答仍是会话，持续执行进入 WorkRun，项目只组织用户拥有的会话与工作，成果使用带版本的 ArtifactRevision。
- V440：新增 WorkProjection v2，把目标、验收条件、执行位置、能力选择、Work Map、恢复入口、协作、自治级别和成果批注投影为同一份 owner-bound 服务端事实。
- V441：桌面工作总览和工作画布读取同一 WorkRuntime；普通用户看到目标、进度、依据、成果和下一步，内部工具与框架细节继续留在管理界面。
- V442：Chat 输入框默认只保留“自动安排”，高级能力收进可展开区域；用户表达目标，系统再依据真实能力解析执行路线。
- V443：Android 工作台改为指挥与接力界面，消费同一 WorkProjection，不复制桌面诊断页。
- V444：桌面项目工作区支持创建、筛选与会话归属；项目更新、会话归属和读取均执行 owner 校验，外部与不存在对象返回同一不可枚举结果。
- V445：桌面与 App 使用 bearer-header SSE 接收增量事件；断线后从游标恢复，60 秒轮询只作为修复通道，令牌不进入 URL。
- V446：新增持久化执行租约。领取、心跳、释放都绑定 owner、代次和幂等键；过期设备不能释放或覆盖后继租约。
- V447：能力解析按 API/MCP、受控浏览器、Computer Use、人工步骤的顺序给出可解释路线；未知工具不会被假定为只读。
- V448：Android 命令 outbox 保留稳定命令 ID；成果批注在超时或断网时加密入队，重连后使用同一幂等键核对，避免重复副作用。
- V449：工作画布增加 Work Map，展示任务、成果、依赖与阻断关系；Artifact 仍通过真实版本和内容哈希进入因果链。
- V450：支持对成果指定页、幻灯片或区域提出版本绑定的批注。批注只使目标成果变为待更新，不伪造完成或验证结论。
- V451：多智能体由确定性收益门决定是否拆分，考虑并行收益、协调成本、共享写风险和依赖风险；模型自评不参与放行。
- V452：新增 copy-on-write Agent 候选分支与清单；只有 integrator 可在哈希匹配后合并，委派执行不能直接写主工作区。
- V453：用户侧只展示角色、任务、状态、阻断和交付摘要，不暴露隐藏推理、工具正文或私有执行参数。
- V454：沿用确定性上下文压缩检查点，保留原始/最新目标、明确约束、未解决事项、持久化工具与验证状态、来源标识和成果引用；压缩文本不作为执行证据。
- V455：恢复中心区分会话续接、成果历史版本和执行检查点，缺少真实检查点时不会显示为可恢复。
- V456：演示转工作流只产生候选；只有真实重复演示、验证回执和稳定技能版本齐备时才可晋升。
- V457：主动收件箱只投影有依据、可取消、受预算约束的建议；不因模型建议自动执行外部副作用。
- V458：自治级别仅开放 A0–A4，且必须有来自评测服务的验证回执；A5 明确不可用。项目不声称 AGI，也不把页面文案当成能力证明。

## 安全与一致性

- WorkRun、Project、Conversation、ExecutionLease 和 ArtifactAnnotation 均绑定 owner。
- SSE 使用 `Authorization` 请求头，不把 access token 写入查询参数、日志或浏览历史。
- 外部页面、上传文件、工具输出与仓库差异继续按不可信数据处理，不能覆盖系统或用户指令。
- 多智能体写入先进入隔离候选分支；主工作区的合并需要 integrator 和内容哈希。
- 新增数据库 schema 28，只做可重复执行的增量迁移，不删除历史工作、会话或成果。
