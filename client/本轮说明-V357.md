# HashMM V357 本轮说明

日期：2026-07-19  
版本：Backend `V357`，Desktop / MCP / Native `1.17.13`，App `1.10.61`（versionCode `102`）

## 本轮结果

1. 左侧一级导航不再单独放“浏览器”。浏览网页已并入“当前工作”和 Chat 工具栏，仍在 Chat 右侧打开，不再形成孤立产品区。
2. “当前工作”顶部新增统一能力带：回到对话、浏览网页、工作画布、多智能体、电脑操作。点击后切回同一个 Chat，并启用对应真实模式；窄空间只保留图标。
3. 修复“页面已经显示，但上方仍保留打开失败卡片”的竞态：只有主文档 `did-finish-load` 才记录最终成功；成功导航明确清除中间跳转错误，`loadURL` 的中间重定向拒绝不会覆盖已成功加载的最终页面。
4. 浏览器新增“引用网页选中内容”：只读取用户在当前页面主动选中的最多 4000 字，经窄 IPC 返回 Chat；内容标记为不可信网页数据，不会伪装成系统指令或知识库证据。
5. 画布、多智能体、Browser Use 与 Computer Use 继续共用当前 Chat 的上下文和结果回帖。多智能体入口会打开真实预览分工面板；画布入口打开真实模板/创建菜单；电脑操作入口启用本机工具循环。
6. App 与桌面端统一公开任务类型为 `browser_use` / `computer_use`。服务端把它们兼容映射到旧 runner 的 `[[AGENT]]` / `[[CU]]` 前缀，已安装旧客户端无需同时升级。
7. App Chat 新增多智能体入口；从某个会话打开时沿用该 `conv_id`，团队分工、独立线程状态、控制室画布和最终汇总回到原会话。只有从工作台单独新建团队时才创建新结果会话。

## 安全与正确性边界

- 远程网页继续使用 `persist:browser-use` 隔离分区，`sandbox=true`、`nodeIntegration=false`，没有页面 preload 或 HashMM 宿主 IPC。
- 页面选中内容是用户引用的上下文，不是 Agent 已读取证据；需要网页取证或操作时仍走 Browser Use 并生成工具轨迹。
- Browser Use / Computer Use 需要同账号桌面 runner 在线；App 离线时任务可排队，但不会伪装成已经执行。
- 多智能体角色保留独立 `thread_id` 和父线程关系，汇总回同一会话；本轮没有把普通 RAG 团队伪装成本地代码 worktree。
