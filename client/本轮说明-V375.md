# HashMM V375 本轮说明

发布日期：2026-07-22

## 本轮交付

- 同账号桌面运行器与 App 工作台使用受认证、所有者隔离的运行事实，不再用远控主机数猜测“电脑在线”。登录令牌更新会立即重新登记，长任务心跳持续续约。
- Chat、文档工坊和右侧产物栏共用确定性的 Word、PPT、Excel 结构检查。桌面端可以把单个会话文件交给 Windows 已注册办公应用，检测修改后由用户显式同步回原会话；无效 Office 文件不会覆盖原文件。
- Android 文件预览增加 OpenXML MIME 交接。vivo 办公套件或其它本机办公应用只要注册 DOCX、XLSX、PPTX 即可被系统选择；没有使用闭源包名、私有 URI 或未公开云接口。
- 远控信令增加登录凭据恢复、有界退避重连和连接代次隔离。隐私能力明确为“远端内容保护”，不再误称物理屏幕熄灭。
- 移除安装包内第三方公共 TURN 默认账号。默认只有 STUN；严格 NAT 或企业网络必须配置自有 TURN 服务与凭据。
- 新增 `hashmm.design-quality.v1` 和 `hashmm.rag-diagnostics.v1`，只陈述静态检查或运行证据能证明的事实，无法评估项明确保留为未知。

## 明确保留的边界

- vivo 办公套件为闭源产品，本轮实现的是操作系统标准文件关联兼容，不宣称 vivo 私有协议、云同步、账号或跨设备 API 兼容。App 打开的是下载到本机的副本；手机侧编辑不会自动回传任务。
- UU 远程为闭源产品，本轮没有复制或声明兼容其信令/传输协议。HashMM 使用自己的 WebRTC、配对、权限与审计链；稳定中继依赖管理员自有 TURN。
- 桌面端 Office 回传是用户显式动作，并在覆盖前做结构验证；它不能替代 Office 应用自身的语义正确性、宏安全或人工内容验收。
- 本轮发现旧启动脚本历史上曾包含真实 JWT、Supabase service key 与搜索密钥。当前脚本已改为环境变量 fail-closed，但旧值应立即在相应服务端轮换；服务器部署还应更换默认管理员密码。
