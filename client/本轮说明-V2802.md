# HashMM V2802 本轮说明

本轮修复的是远程链路的真实阻塞，而不是继续延长 App 转圈时间：日志证明桌面批准成功后，服务端没有收到抓屏、offer 或兼容帧。V2802 为主进程到抓屏进程增加可确认、可重试的消息交付，并增加不依赖隐藏渲染进程的原生兼容首帧路径。

权限规则同步收口：同一 Supabase 账号的 Remote v4 设备通过双端一次性票据认证后自动授权；验证码连接首次仍须校验，成功后建立可撤销的设备信任，主机只保存令牌哈希，后续无需重复输入。关机、重启等危险动作仍单独确认。

- Product/API `28.0.2`
- Backend `V2802 / 2.8.2`
- Desktop/Installer `17.0.2`
- Remote protocol `hashmm.remote.v4`
- Android 保持 `12.0.0 (280)`，与本轮协议兼容

完整技术说明见 `docs/HASHMM_V2802_REMOTE_TRUST_MEDIA_RECOVERY.md`。
