# HashMM V428 本轮说明

本轮把 V390–V425 的主链按真实执行状态重新收口，并修复了上一轮只在页面上显示能力、实际执行路径仍可能退回兼容空壳的问题。

## 已完成

- `SmartAgent` 兼容入口改为调用真实 `ReactAgent`，工具调用必须经过带执行上下文的治理回调；无作用域 worker 不再执行。
- 多 Agent 兼容执行器采用有界并发，所有角色都会得到结构化结果；部分失败不会被伪装成统一成功。
- 长任务与 WorkRuntime 的绑定状态现在有 `linked / degraded / not_configured` 三态；跨端记录不可用时会显示原因。
- 长任务事件改用 `append_event_once` 和确定性幂等键，重连或重复回调不会重复推进事件游标。
- Graph RAG 只有在 `kg_query` 真正挂载到 Chat 时才标记为 wired；沙箱只有隔离后端和执行工具同时存在才标记为 wired。
- 版本统一为 Backend V428、Desktop/MCP/native source 1.25.0。
