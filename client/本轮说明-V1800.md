# HashMM V1800 本轮说明

## 版本组合

- Backend/SDK：V1800 / 1.8.0（服务版本 18.0.0）
- Desktop、WebUI、MCP、Native Installer：9.0.0
- Android：6.0.0（versionCode 180）
- 远程协议：hashmm.remote.v2

## 已实现

1. 同一 Supabase 身份下建立 owner-scoped 稳定设备目录，不再把进程内随机 connection ID 或旧 Supabase presence 当作设备真值。
2. 桌面 host 和 App viewer 通过 HTTPS 换取短期单次票据后接入 WSS；稳定设备采用 10 秒心跳、35 秒租约和 generation fencing。
3. 桌面 main process 在票据消费后断线时重新签发并重建宿主；Renderer watchdog 独立于 token 刷新周期。
4. Android 使用 App 自有持久安装身份，增加注册超时、有限重连、V2 注册信息及权威设备快照状态。
5. 新增 V2 设备/票据/自诊断 API、V3 readiness、大小/首帧超时、票据上限和无敏感信息审计。

## 验收口径

- 代码与本机构建结果以本轮实际命令输出为准。
- 真实不同运营商、对称 NAT TURN、24 小时 soak 与多实例 shared broker 仍必须在部署环境取得回执；文档和环境变量不算通过。
- 未配置 Authenticode/Android 发布者 keystore 时，校验哈希与构建成功不能替代发布者签名身份。
