# HashMM V602–V610 本轮说明

日期：2026-07-28  
Backend：V610  
Desktop / MCP / Native：1.37.0

## 本轮目标

本轮没有继续增加与 Chat 割裂的功能页，而是把画布、协作、今天、项目、资料库、插件和设备接力统一改造成用户可直接理解的工作空间。界面只负责表达目标、选择、进度和结果；真实文件、项目、团队运行、插件能力、资料权限和远程桥接仍由既有服务端与桌面窄权限接口提供。

## 画布与协作

- 画布首页从内部模板列表改为五种用户结果：自由创作、整理工作、比较决策、呈现数据和共同完成。
- 创建画布继续使用当前对话和真实文件 API；最近画布、模板、版本及右侧 Artifact 预览没有另建展示数据。
- 多 Agent 协作改为“说明工作 → 确认分工 → 查看结果”。用户先填写目标、交付物和完成条件，再选择自动安排或手工角色，以及并行推进或依次接力。
- 启动前调用真实预览，运行中继续使用 `teamStart`、`teamStatus`、`teamStop`、`teamRetry`；资料依据与详细执行记录按层级展示，最终结果回到原 Chat。

## 今天、项目与资料库

- 今天页只突出需要用户决定、正在处理和最近完成的真实事项；同步信息退到刷新提示，不再占据首屏。
- 项目使用两步工作简报：先说明要完成什么，再约定交付物和完成条件；项目仍保存为账号隔离的服务端对象。
- 资料库支持按文档、PDF、演示和表格筛选；选择一份或多份资料后，可在同一 Chat 中提问、比较或制作成果。
- 内部切片数量、检索实现和运行模块不再直接暴露给普通用户；来源与可核对证据仍保留。

## 插件与设备接力

- 插件中心使用“插件 / 我的工作方法”两条用户路径，并按资料、创作、自动化、协作和持续工作分类。
- 内置能力明确标为“无需安装”；外部插件仍只展示服务端已发现、已校验并已信任的真实清单，不能通过前端选择扩大权限。
- 设备页改为“在另一台设备继续”，分别承载 App 接力、HashMM 安全控制、Windows 远程办公和 Moonlight 流畅画面。
- 虚拟网卡、地址、端口、EasyTier 与连接诊断收进“连接帮助”；底层仍走现有受保护 IPC、短时配对和用户显式授权。

- 第三方插件仍需要管理员提供并信任有效清单；没有清单时显示真实空态，不伪造商店安装或 OAuth 已接通。
