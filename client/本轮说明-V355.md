# HashMM V355 本轮说明

日期：2026-07-19  
范围：Desktop / Frontend / Backend / Native Installer；App 本轮未改动  
版本：Backend `V355`，Desktop / MCP / Native `1.17.11`

## 本轮完成

### 1. 右栏浏览器不再使用不稳定的 renderer WebView

- 右栏网页迁移到 Electron 主进程 `WebContentsView`。React 不再创建 `<webview>`，只负责地址栏、可信操作按钮和视图边界。
- 远程页面固定在 `persist:browser-use` 隔离分区，启用 Chromium 沙箱，关闭 Node、子框架 Node、preload 和宿主 IPC。
- 主进程持有加载、错误、标题、历史导航、跨站授权、弹窗治理与生命周期；React 重挂载通过 owner token 避免旧组件误卸载新页面。
- Electron 实跑测试使用本地 HTTP 页面检查了 DOM、CSS、视图 bounds 和实际截图像素，确认不是“方法调用成功但仍白屏”。

### 2. 外部浏览器优先 Google Chrome

- “外部打开”和其他桌面 HTTP 外链入口优先从 Windows/macOS/Linux 的固定 Chrome 安装位置启动 Google Chrome。
- Chrome 不存在或进程启动失败时回退系统默认浏览器，结果会如实回报为 `chrome` 或 `system`。
- 可执行文件路径不接受用户输入；URL 重新解析，只允许不含账号密码的 HTTP/HTTPS。

### 3. Browser Use、Artifact、Computer Use 回到 Chat

- 右栏“交给 Agent”只附加当前 URL、页面标题和 `agent_read=false`，随后由真实 Browser Agent 在受控浏览器重新打开并读取；不会把用户屏幕上的页面冒充为已取证正文。
- Artifact 继续提供真实编辑、自动保存、版本、源码/预览、差异、下载/发布、多产物切换和“让 Agent 修改”；没有新增只能展示的 Demo 页面。
- 本地 Computer Use 继续在受限动作工具循环中消费浏览器、画布、文件等 Chat FeatureContext；附件被转义并放入不可信数据边界，任务成功才消费，失败保留供重试。
- 登录、验证码、支付、提交、下载、发布、删除等高影响动作仍受既有权限、审计和人工确认约束。

### 4. 多 Agent 真正使用当前 Chat 资料

- 启动团队时把当前 Chat 中用户显式附加的浏览器、Artifact、文档、文件等上下文一并提交，而不是让多 Agent 与主会话割裂。
- 后端统一执行白名单、数量/字符预算、截断、密钥脱敏和边界伪造转义；所有角色与汇总者使用同一份规范化资料。
- 附加资料明确不是知识库检索证据，不分配 `[N]` 引用，也不会因为带入了一个网页就取消“外部事实未验证”的约束。
- 团队状态只保存附件种类、标题、数量、截断/脱敏等可观测元数据，不通过状态接口回传原始网页或文档内容。
- 团队启动成功后才一次性消费附件；启动失败时仍留在 Chat，可修正后重试。

### 5. 团队会话权限与打包失败修复

- 多 Agent 往会话写控制室 Artifact、启动消息或最终汇总前，必须 owner-check `conv_id`；无权与不存在对象继续共享不可枚举错误。
- 用户上传日志中的打包失败已修复：浏览器业务模块不再早于 `uncaughtException` 保护网加载。
- `test_packaging_integrity` 再次通过，保证安装包若漏掉业务依赖，用户会看到可恢复中文错误，而不是 Electron 原始崩溃框。
- `build-all.bat` 横幅同步为 V355，避免成功产物仍打印旧 V352。

## 机制校准与限制

- Electron 官方不建议继续使用 `<webview>`，V355 因而采用 `WebContentsView`，并按官方安全要求隔离远程内容、关闭 Node。
- 右栏浏览器使用 Electron 自带 Chromium；“外部打开”才是本机 Google Chrome。两者不能混写成同一个浏览器进程。
- 用户可见右栏与 Browser Agent 共享受控站点策略/隔离分区，但 Agent 仍按 URL 重新读取并产生自己的轨迹与证据。
- 多 Agent 是受控主任务—子任务编排、共享任务资料、状态/结果回传；当前不宣称具备 Claude Code agent teams 的全部点对点消息协议或每角色完整 worktree 隔离。
- Artifact、Computer Use 和 Browser Use 的“已完成”只以文件、工具结果、轨迹和测试为证据，不以模型文字自证。
- App 本轮未修改，也不声称已同步本轮 Desktop 浏览器迁移。
