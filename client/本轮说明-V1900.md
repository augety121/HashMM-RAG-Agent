# HashMM V1900 本轮说明

## 版本

- Backend/SDK：V1900 / 1.9.0（服务版本 19.0.0）
- Desktop、WebUI、MCP、Native Installer：10.0.0
- Android：7.0.0（versionCode 190）
- 远程协议：`hashmm.remote.v2`（状态语义升级，不伪造 v3 wire protocol）

## 本轮完成

- 修复隐藏远程主机的加载竞态：增加 renderer-ready/bootstrap 握手、渲染失败状态和 fresh-ticket 恢复。
- 桌面设备页以 `/api/remote/v2/devices` 的 `remote_ready` 为远程可用真值，Dispatch runner 单列为 Agent 执行节点。
- App 不再用“V2”冒充存在可连接电脑，明确区分通道连通与远程主机上线。
- 完整导入 Agency Agents 271 个 MIT 角色（18 类），加上 14 个核心角色共 285 个；支持搜索、分类和懒加载。
- 自动编队使用有界候选，第三方角色不自动获得工具或权限。
- Today 去除首要待办重复展示；自动任务、插件、设备接力统一为更平、更克制的工作台视觉。
- 去除工作对象行横向位移动画和插件卡片上浮动画。

## 验证口径

本轮已完成以下发布验证：

- 后端全量：`1692 passed, 8 skipped`。
- 前端：61 个测试文件、226 项测试通过；TypeScript 类型检查与生产构建通过。
- 桌面端：全部 Node 契约测试通过；原生发布源码门禁通过。
- Android：Kotlin 编译、Debug 单元测试和 APK 构建通过。
- 桌面安装器：Desktop `10.0.0` / Backend `V1900`；EXE 实算 SHA-256 与 `.sha256`、`.release.json` 三方一致。
- 服务器包：1354 个 ZIP 条目；包含 271 个上游角色、角色索引和 MIT 许可证，不包含真实 `.env`。

当前安装器未配置 Authenticode 发布者签名，Android 交付物为 Debug 签名 APK。SHA-256 仅证明文件完整性，不能替代发布者身份。未配置共享远程 broker 时，多实例信令仍不宣称可用。
