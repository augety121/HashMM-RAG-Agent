# HashMM V705 本轮说明

## 本轮目标与结论

V705 不再继续堆一组彼此孤立的“插件能力”，而是把 HashMM 收口成可恢复、可审计、可验证的 Agent 运行骨架。Chat 仍是用户主入口；项目归属、附件范围、公开任务链、审批、检查点、后台执行、检索证据、成本和评测都投影到持久事实，而不是依赖模型自述。

本轮没有复制或蒸馏 Codex 的隐藏思维链。系统只持久化可公开核验的任务链：目标、约束、计划、动作、工具回执、审批、证据、检查点、验证和交付状态。供应商原始 reasoning、`<think>` 与模型私有推理不进入公共 API、SSE 或界面。

## 已实现

1. **稳定公共 API**：新增 `/v1/info`、能力与模型发现、Threads/Turns/Items、Responses、Chat Completions、Runs、审批、命令、检查点、事件和用量查询；原 `/v1/search`、`/v1/rag` 保持兼容，公共 API 仍默认关闭。
2. **原子幂等与账号边界**：写请求必须提供 `Idempotency-Key`；同账号、同路由、同键只允许一个执行权，同键异载荷返回冲突，完成结果可重放。对象 ID 全部 owner 校验，缺失与越权按不可枚举方式处理。
3. **持久 Responses 与后台执行**：响应和结构化事件写入 SQLite，SSE 支持按 `Last-Event-ID`/`after` 重放。`background=true` 进入有界后台队列并与 Responses 共享同一个 WorkRun；服务重启时无法重建的任意 Python 闭包进入 `interrupted`，不盲目重放。
4. **统一任务事实源**：后台作业、公共响应与现有 Chat 共用 WorkRuntime；状态集合补齐 `created`、`paused`、`retrying`、`verifying`，保留旧状态兼容。最终生成状态是 `delivered`，仍需验收证据才能称为用户任务完成。
5. **严格资料范围**：稠密和稀疏结果经过融合后再次按显式文档白名单裁剪，堵住 BM25/RRF 将未选择文档带回结果的路径；返回契约包含范围、执行标志、泄漏计数和 Expected Gain 轨迹。
6. **Expected Gain 检索选择**：确定性计算相关性、引用、信任收益，以及 token、延迟、来源风险和冗余成本；全部低于阈值时只保留一个最佳候选，避免无证据空跑。可用 `HASHMM_EXPECTED_GAIN=0` 回退。
7. **知识演化隔离区**：CoEvoKG 风格候选按账号和项目隔离；来源与 SHA-256 为强制字段，经审查、冲突处理和通过的评测后才能提升为不可变版本，并支持父版本校验和回滚。生产知识图谱不会因一次模型输出被自动覆盖。
8. **LoHoSearch 评测适配**：部署者通过 `HASHMM_LOHOSEARCH_DATA` 提供数据及 SHA-256 清单；支持 smoke/CI/full 预算、准确率、工具步数、P50/P95 与条件分解。没有官方快照和完整 544 条 full 执行时，报告明确标为不可比。
9. **成本护栏与 SDK**：模型调用前预留预算，结束后结算用量；现阶段没有供应商计费回执时明确标注为估算。无第三方依赖 Python SDK 支持新增对象和幂等写接口。
10. **前端任务面板**：右侧继续使用现有公开任务链，展示统一状态、事件、审批和检查点，不新建第二套任务系统。

## 安全与兼容约束

- API Key 只接受 Bearer 或 `X-API-Key` 请求头；持久化所有者只保存不可逆指纹，不记录明文密钥。
- 上传文件、网页、命令输出、仓库 diff 与外部评测数据都按不可信输入处理，不能覆盖系统或用户指令。
- 未知工具不视为只读；外部计算、支付、钱包和容器必须经过显式适配、权限、预算与审计后才可启用。
- 新表采用增量 `CREATE TABLE IF NOT EXISTS`，不删除现有会话、OCR、WorkRuntime 或知识数据。

## 验证口径

- 后端完整测试：`1615 passed, 8 skipped`（最终发行门禁重新运行后记录）。
- 前端：54 个测试文件、201 项测试通过；TypeScript 检查与生产构建通过。
- V705 集成回归覆盖 48 路并发幂等、跨账号对象隔离、事件重放、后台实际执行、预算、严格文档范围、Expected Gain、知识版本冲突/回滚、LoHo 清单验真和 SDK 请求头。
- 桌面源代码发布门禁必须验证前端成品、内置 Python 依赖指纹、核心模块导入以及 Desktop/MCP/Native 版本一致。
- 服务器 ZIP 必须由 `scripts/package-server.ps1` 生成，内含逐文件 SHA-256 JSON 清单；打包后再次拒绝路径穿越、重复项、桌面/测试/用户数据/数据库/密钥/模型/索引和旧归档。

## 仍然保留的真实边界

- 供应商流式生成中途进程崩溃，不能从供应商内部 token 光标无损续写；可从最后一个持久安全检查点恢复或重试。当前 Responses 的事件重放是 HashMM 已持久化事件重放，不宣称供应商 token 级断点续传。
- Chat Completions 兼容入口当前返回完整 JSON；结构化流与断点重放由 Responses API 提供。
- 通用后台 Python 闭包在服务重启后不能安全反序列化，故明确中断；具有确定性重放处理器的 OCR 队列仍按自身租约与重试机制恢复。
- LoHoSearch 官方数据未随代码分发，本轮不声称任何官方 benchmark 分数；证据支持率等需要轨迹标注的数据在缺失时返回 `null`，不会猜测。
- KG 演化只更新隔离区的活动版本指针，不自动改写生产 `graph.json`；上线生产图仍需显式导出/迁移流程。
- Cloudflare Computer、Wallet、x402、Billable Usage API 均未伪装为内置能力。当前只提供只读能力说明、预算账本与适配边界；真实接入需要届时核对正式 API、账号、支付权限和部署环境。
- 本轮交付服务器 ZIP 和桌面源码一致性门禁，不运行完整 Qt/Windows 安装器构建，也不把旧 EXE、旧 `.release.json` 或未做的 Authenticode 签名冒充为 V705 成品。
