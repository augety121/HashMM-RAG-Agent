# HashMM V498 本轮说明

V474–V498 的目标不是再增加一批独立入口，而是把 RAG、Graph Engineering、Chat、长任务、浏览器、Computer Use、多 Agent、MCP、Hooks、画布和跨端接力收敛为同一份可验证工作事实。用户表达目标，系统依据当前账号、设备、能力和证据决定执行路径；模型输出本身不构成执行、授权或完成证明。

## 关键安全边界

- 有身份的检索请求必须把 `owner_id` 传到检索器；不兼容的旧适配器失败关闭。只有显式无身份的本地兼容路径可省略旧适配器不认识的参数。
- ACL 异常、未知工具副作用、关键 Hook 异常、契约篡改、租约不匹配和缺少有效完成回执都不会降级为成功。
- 外部网页、上传文件、命令输出、仓库差异和工具结果始终作为不可信数据，不得覆盖系统或用户指令。
- Browser Use 和 Computer Use 只有真实运行事件能形成执行事实；页面文案、模型叙述和设备自报不等于独立验证。
- App 与桌面端共享账号和 WorkRun，但权限按设备与短期租约约束；跨端接力不是跨设备自动扩权。
