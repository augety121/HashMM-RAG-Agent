# HashMM V386 本轮说明

日期：2026-07-22

## 结果

本轮完成的是执行框架接线，不是再增加一批独立页面。Chat、长任务、工具、上下文压缩、多 Agent、运行评测、桌面右栏和 App 运行轨迹现在共用 `hashmm.agent-harness.v1` 与 `hashmm.context-engine.v2` 的有界事实链。

模型在每轮开始前只能看到同时满足“存在 schema、服务端作用域授权、存在真实执行器”的能力；运行中不能自行扩权。普通与流式子 Agent 共用同一准入和停止生命周期。上下文超过预算时，系统先执行 `PreCompact`、写属主绑定检查点，再压缩内存消息；本轮结束再记录恢复代际。RAG 和工作区内容即使被缓存或压缩，仍是不可信数据，不会被提升为系统指令。

桌面端右侧运行面板显示冻结作用域、审批/联网模式、真实能力数、生命周期事件、上下文代际/检查点和子 Agent 数。App 运行页读取同一份 harness 与 context lifecycle，展示终态、真实能力、压缩代际、检查点、子任务和隐私边界。详细参考审计见 `docs/reference-audit-V386.md`。

## 明确限制

- 本轮没有生成新的 Windows 安装程序，因此不把源码发布闸门等同于安装器发布成功。正式发布仍须执行 `installer-native/build-all.bat`，并核对 EXE、`.sha256` 与 `.release.json` 三方一致。
- Android 交付物为 debug-signed APK，不是应用商店正式签名包。
- 上下文检查点证明系统保存了有界恢复状态，不证明摘要中的外部事实为真；事实仍必须回到原始 RAG 来源和核验账本。
- 运行轨迹证明 HashMM 观察到了动作与结果状态，不证明模型文字或现实世界副作用一定正确。
- 当前正在进行的单次模型/外部工具调用不能被进程内标志强制硬杀；停止在安全检查点生效，迟到结果不会被采纳为完成。
- App 是同账号桌面工作的伴随入口。本地文件、Browser Use、Computer Use 等特权副作用仍由在线桌面执行器执行。
