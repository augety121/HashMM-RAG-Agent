HashMM 用户协议与隐私政策

更新日期：2026-06 · 简版

1. 软件性质

HashMM 是本地优先的 AI 工作台。程序与数据均安装、运行在您自己的电脑上。

2. 数据与隐私

  • 您的知识库、对话记录、配置仅存储在本机用户目录，软件不会将其上传至开发者服务器。
  • 仅当您主动配置云端模型 API 时，相关请求内容才会发送给您所选择的模型服务商，受其条款约束。
  • 软件不收集遥测，不内置广告与第三方跟踪。

3. 安装与卸载

  • 安装过程不修改系统全局配置；运行环境与系统隔离。
  • 卸载默认保留您的数据目录，重新安装即可恢复；如需彻底清除，请手动删除用户数据目录。

4. 许可与免责

  • 您可在自有设备上安装、使用本软件。
  • 软件按“现状”提供；在适用法律允许的最大范围内，开发者不对因使用本软件造成的数据丢失或损失承担责任。请妥善备份重要数据。

5. 其他

继续安装即表示您已阅读并同意上述条款。
