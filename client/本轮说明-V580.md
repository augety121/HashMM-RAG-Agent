# HashMM V571–V580 本轮说明

日期：2026-07-27  
Backend：V580  
Desktop / MCP / Native：1.34.0

## 本轮目标

本轮没有继续增加与 Chat 平行的演示页面，而是把现有浏览器、Computer Use、多 Agent、画布、资料和扩展能力收回同一段对话。用户看到的是“要完成什么”和“采用什么工作方式”，服务端仍以账号、权限、工具注册和真实回执作为边界。

## 已实现

### Chat 与画布

- 输入框默认保留附件、截屏和自动工作方式；其余能力进入可响应式折叠的工作方式面板，窄窗口不再把文字挤成竖排。
- 资料范围只读取当前账号的知识文档，以搜索和多选弹层展示；选中数量在工具栏中保持紧凑。
- 画布当前版本可交给受控浏览器做事实核验，或交给多 Agent 做事实、逻辑与可读性并行评审。
- 所有交接都通过 Feature Context 回到当前 Chat，由用户审阅提示后发送；模型不能自行把评审文字当成文件覆盖回执。

### 插件

- 左侧栏新增插件中心，卡片来自服务器真实插件清单，不生成虚假市场数据。
- 管理员只有提供与清单一致的 SHA-256 才能信任并加载插件；普通用户只能选择已经信任和加载的插件用于 Chat。
- 选择的插件 ID 随 Chat 请求进入后端，后端与当前已激活集合求交集，AgentLoop 只注册该集合的工具定义和执行器。
- 未显式保存过选择时保持历史兼容；显式选择空集合时不向该 Chat 注入任何插件工具。

### 个人 Skills

- 用户设置新增 Skills 页面，支持 ZIP、公开 HTTPS、GitHub、Codex、Claude Code 和兼容 Agent Skills 目录。
- 个人 Skills 使用账号哈希目录隔离，普通用户不能读取、启停或删除其他账号的 Skill。
- Chat 先按相关性读取 Skill 元数据，再渐进注入匹配正文；失败不会阻断主对话。
- 导入项只作为不可信指令数据，不执行脚本，也不自动获得工具、文件或网络权限。
- ZIP 限制 50 MB 输入、400 个文件、10 MB 单文件和 100 MB 总解压体积；拒绝路径穿越、加密项和非 ZIP 输入。
- 网站导入只允许公开 HTTPS，拒绝凭据、非默认端口和非公网解析地址，并对每一次跳转重新校验。

## 明确限制

- 插件中心不伪造第三方插件商店；服务器没有安装和通过管理员信任的插件不会显示为可用。
- 网站导入已限制公开 HTTPS 和逐跳地址，但公开站点内容本身仍是不可信数据。
- Browser Use、Computer Use 和多 Agent 是否能实际执行，取决于当前设备在线、权限、工具注册和服务端能力；界面入口不是完成证据。
- Windows Authenticode、真实公网多设备、对称 NAT、自有 TURN 与 24 小时稳定性需要真实发布环境验收。
- 本机构建未配置 Authenticode 证书，因此生成的是内部测试安装包，不应直接作为已签名公开发行包。
