# HashMM V621 本轮说明

日期：2026-07-28  
Backend：V621  
Desktop / MCP / Native source：1.38.1

## 本轮完成

### 1. 账号连续性与项目/最近

- 新增 `frontend-next/lib/accountWorkspaceCache.ts`，把会话、项目和当前项目选择写入带 schema/subject 的账号隔离缓存。
- `saveAuth`、退出、重新认证和启动恢复路径均显式保存/加载当前账号缓存；旧全局 `hmm_s` 只允许被首个已识别账号迁移一次，随后删除。
- 侧栏使用 Codex 风格的“项目 + 最近”结构，项目下显示关联 Chat，最近按 `updated_at` 分组；搜索覆盖项目、对话和工作记录。
- 缓存不是授权依据。登录后仍调用服务端同步并按服务端 owner/权限结果裁剪本地投影。

### 2. 用户工作空间

- “今天、资料库、画布、协作、我的、设备接力”使用统一的用户工作对象表达，工具和 Agent 细节继续留在按需详情。
- “我的”复用个人资料、Skills、记忆与偏好、资料/知识包、设备接力和通知的真实链路。
- 画布从最近账号会话中索引真实 HTML 产物，打开后可回到来源 Chat；协作启动、状态、停止和重试仍使用现有运行接口。
- 新对话会清除工作区状态并返回 Chat，避免侧栏高亮变化但主内容仍停留在上一工作区。

### 3. Office 交接回执与输入框

- `desktop/services/office-handoff.js` 返回 `hashmm.application-harness.v1`，包含资源修订、观察/读取/提交能力和明确的任意文件/命令禁止标志。
- Artifact 面板消费回执显示真实交接状态，而不是把模型文本当作完成证据。
- 问答栏文字收起断点调整为 620px；窄布局隐藏文字、保留图标，宽布局显示常用能力名称。
