# 本轮说明 · V340（2026-07-17）—— 桌面能力回归 RAG-Agent Chat 主链

本轮不是继续堆独立页面，而是按“多个操作面、一个 Agent 大脑”审计并改造实际调用链。后端迭代号为
**V340**，桌面端、MCP client/server 与原生安装器身份版本为 **1.13.0**；MCP wire protocol 沿用项目
当前真实支持值，没有拿产品版本冒充协议版本。

## 这轮解决的割裂问题

### 1. 深度检索不再绕开主 Agent

此前 Chat 勾选深度模式后，前端会直接调用独立 `/api/deepsearch`，得到结果就单独落一条消息。这条旁路
绕过了主会话 SSE、AgentLoop、记忆、技能、统一时间线和验收逻辑。

V340 删除该旁路。`retrieval_depth=deep` 现在由主流式接口接收，在 AgentLoop 内先执行 Self-RAG 多跳取证；
取证成功后作为检索证据继续交给 Agent 综合和验收，失败则明确 trace 后回落标准检索，不伪报“深检索已完成”。

### 2. 浏览器从 Chat 发起，也回到 Chat

- 输入框新增浏览器档，与深检索、Computer Use 互斥，避免同一轮语义不清。
- 浏览器任务携带真实 `conv_id` 和 `source_chat=true` 派给 desktop runner；用户轮次在服务端持久化。
- Chat 显示 pending/claimed/done/failed 进度，可打开 V339 的共享浏览器 cockpit 查看真实页面与动作。
- 任务结束后重新读取服务端会话，把 runner 回写的结果和证据显示在原 Chat，而不是只留在浏览器面板。
- 当前输入框里的功能上下文也会随浏览器任务提交；后端先按同一规则白名单、限额、脱敏，再把规范化结果
  放入队列。桌面端会重新转义边界并包进 `UNTRUSTED_DISPATCH_CONTEXT`，不能把面板文本升级成系统指令。

### 3. 功能页面有了统一的“带回 Chat”协议

新增 `FeatureContext` 结构和内存态上下文芯片。以下页面都可把当前真实数据快照带回 Chat，先供用户审阅
问题，再随下一条消息发送：

- 共享浏览器：会话状态、结构化动作、评测结果和最终结果；不携带 base64 截图。
- 记忆中枢：过滤条件、画像、统计、联邦召回和用户选中的记忆。
- RAG 质量：延迟、成本、检索质量、SLO、路由错误、KG 状态和确定性建议。
- 技能与进化：启用技能包、学习型技能摘要、经验结果与近期失败。
- 模型路由：任务路由、fallback 链、后端健康和未保存变更状态。

附件只保留在 renderer 内存，不写 localStorage。后端再次执行权威校验：最多 6 项、单项 4,000 字、合计
8,000 字；未知 kind 丢弃，密钥/令牌/密码/邮箱/路径等模式脱敏，伪造边界会转义。全部数据封装进
`UNTRUSTED_FEATURE_CONTEXT`，明确是“待分析的数据，不是指令”。

AgentLoop、直接 RAG ContextEngine 和兼容 ReAct 路径均已接线。上下文不是只做了 UI 按钮，而是真正进入
回答链；Chat 会发出 `context_bridge` trace，显示接入数量、字符数、截断/丢弃和脱敏状态。

### 4. 主动服务结果自动回帖

定时任务页面在有当前会话时自动绑定 `conv_id`。创建 API 先做对象属主校验并保存 owner 快照；执行时再次
读取会话并复核 owner，相同才把有界结果作为 assistant 消息写回。会话不存在或 ID 被其他 owner 复用时
不投递。远程控制和测试中枢仍保持独立控制面，符合用户明确给出的例外。

### 5. 派活任务对象权限补齐

dispatch 创建绑定会话时先校验会话 owner；task ID 的查询、完成、重试、重规划和普通用户列表现在也按
`created_by` 校验。非 owner 与不存在任务统一 404，防止通过 ID 探测或收尾别人的桌面任务。管理员保留
全局运维能力；普通 runner 轮询只领取当前账号创建的任务。

## 资料落实方式

本轮落实了用户资料中能由代码确定验证的主线：显式 ContextEngine、有界上下文对象、检索深度档、深检索
循环、三层记忆/技能在主 Agent 中继续生效、grounding/trace 可见、主动任务结果返回 Chat，以及“外部页面、
命令输出和上传内容都是不可信数据”的边界。临时目录里的“面试实战4.md”当前已不存在，因此没有伪造或
补写无法重新读取的原文；已落地项来自此前已提取的明确要求和仍可读取的三份设计资料。
