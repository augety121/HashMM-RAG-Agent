# HashMM V1200 本轮说明

日期：2026-08-09  
主题：Secure Remote Workspace 3.0 + Agent Retrieval Fabric 1.0

## 已完成

- 新增持久化、owner-scoped 的多提供商 SearchRun/Event/Evidence 基座，支持 fast、verified、deep、rag_live 四种模式。
- 接入百度千帆、Brave、Exa、Google Grounding、Tavily、Serper、豆包兼容和 DuckDuckGo；Bing 从执行链移除并标记 retired。
- Chat `web_search` 统一走检索基座，保留账号显式豆包配置优先级。
- 设置与管理后台支持多提供商账号级/平台级密钥；密钥加密存储，真实探测复用生产适配器。
- Supabase JWT 增加 issuer 校验；代理协议头只信任显式 CIDR。
- 停止向 `app_config` 下发模型 API Key，清理历史 `direct_llm` RLS 暴露和固定弱密码 SQL。
- Secure Remote readiness 升级 v2，加入 HTTPS 公网地址、Supabase 身份、临时 TURN、真实公网验收和 24 小时 soak 门。
- 提供 cloudflared/生产环境模板；未新增或升级 pip 包。

## 诚实边界

- 当前仓库无法替 AutoDL、校园网或运营商修改 `111.115.7.14:20014` 的公网路由。必须配置 AutoDL 公网映射或自有域名 Tunnel 后做校外实机验收。
- 本地未持有用户的 Cloudflare 域名/Tunnel 凭据、TURN 服务和各搜索商真实密钥，因此不把配置模板或适配器单测写成真实公网/供应商验收通过。
- 互证是检索条目级来源交叉，不是事实真伪判定；RAG-live 差异是更新线索，不自动写回知识库。
- 量化 Agent 本轮按用户要求未实施。
