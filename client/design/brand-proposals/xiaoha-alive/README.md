# HashMM 图标提案：小哈 Alive

这是独立设计提案，不接入桌面端、App、安装器或网页资源。

- `01-listener.svg`：推荐方向。倾斜天线、向右上方观察的视线和右侧围巾尾形成明确角色姿态。
- `02-night-shift.svg`：深色高对比版本，适合专业工具与深色系统环境，但与既有浅色品牌距离更大。
- `03-memory-scout.svg`：强化“发现与记忆”叙事，个性最强，也最接近吉祥物而非企业主标。

共同约束：不复制喜茶、小米、Claude 或 Codex 的商标图形；保持 HashMM 原有黑、白、红识别；16px 仍保留头部、眼神和红色信号；不使用文字、渐变、阴影和细碎线条。
