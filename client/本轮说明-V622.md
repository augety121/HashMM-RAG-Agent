# HashMM V622 本轮说明

本轮把桌面端的工作入口收敛为 Chat-first 结构，并重做了工作对象页面的视觉层级。

## 已完成

- 左侧栏移除“我的”，保留“今天、资料库、插件、设备接力”四个稳定入口；“项目/最近”继续保留为可切换的本地工作记录。
- 画布与协作不再作为主导航孤立页面：从 Chat 的工作方式按钮或插件中心启动，沿用当前会话，并通过右侧工作区回到原对话。
- Chat 内协作面板接入 `TeamPanel`，支持在当前会话中查看分工、审批和结果；画布入口打开真实模板菜单，创建结果仍绑定会话文件。
- 设置增加“浏览器与电脑”能力页，可分别启用浏览器、电脑操作、工作画布和多智能体，并从设置直接回到 Chat；开关只控制本机入口，不绕过服务端权限。
- 资料库、项目、今天和画布页面统一为 master/detail 工作对象布局，补充实时同步、待确认数量、项目/资料统计和更清晰的操作层级。
- 插件中心继续使用运行时能力与真实 API 状态；能力卡片的“使用”动作回到 Chat，而不是打开演示页面。
- 统一开关补充 `role="switch"` 与 `aria-checked`，为键盘与辅助技术保留可验证状态。

## 验证

- 前端 Vitest：45 个测试文件、171 个测试通过。
- TypeScript：`npm run typecheck` 通过。
- 后端和桌面端逻辑本轮未改动，发布前仍需按仓库门禁重新跑完整 Python、桌面 Node 与前端生产构建。
- 原生安装器本轮没有重建；现有 `HashMM-Setup.release.json` 仍代表上一份已构建安装包，不能把它当作 V622 安装器。
