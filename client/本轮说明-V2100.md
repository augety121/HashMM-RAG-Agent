# HashMM V2100 本轮说明

## 版本

- Backend/SDK：V2100 / 2.1.0（服务版本 21.0.0）
- Desktop、WebUI、MCP、Native Installer：12.0.0
- 远程协议：`hashmm.remote.v2`（保持 wire compatibility）

## 已实现

1. Remote Host Supervisor：账号 host 的一次性 ticket、WSS 首帧鉴权、心跳、single-flight 建连、有界抖动重连和状态诊断由 Electron 主进程持有。
2. 媒体进程最小化：隐藏页不接触账号 token 或 ticket，只通过 allowlist IPC 获取服务端信令并回传 WebRTC 消息；LAN 兼容通道保留。
3. 远程可观测性：服务端记录 pre-auth disconnect/timeout、阶段、短连接号、attempt 指纹与耗时，不落敏感网络或认证数据。
4. 四个工作台：自动任务、智能体协作、能力与插件、设备接力共享低装饰、稳定 hover、可读字号与无障碍焦点；设备页能区分申请凭证、开 socket、鉴权、已注册、重连、登录过期和拒绝。
5. 插件执行边界：清单、权限声明、管理员 exact SHA-256 信任仍是准入；Python 执行改为短生命周期隔离进程，并在每次调用前后复核摘要。
6. 品牌与安装器：新增 SVG 单一源和 16–1024 PNG 资产；原生安装器采用布局标题栏、可伸缩窗口、默认折叠选项和带百分比进度，欢迎/安装/完成态尺寸一致。

## 仍需真实环境验收

- 同一 Supabase principal 下 Windows host 与 Android viewer 的发现、审批、媒体建立和掉线恢复。
- 有效 TURN 凭据下跨校园网/对称 NAT relay 及 24 小时稳定性测试。
- 多实例服务需要共享 presence/signaling broker；当前 SQLite 单节点状态不能冒充横向扩展。
- Python 插件子进程不是操作系统强沙箱；涉及不可信第三方代码时应进一步采用 AppContainer/namespace 或 MCP 外部进程。
- 正式 Windows 公网分发仍需 Authenticode；未签名成品只能作为测试/内部交付。
- `npm audit --omit=dev` 仍报告 `onnxruntime-node 1.26.0 -> adm-zip 0.5.17` 的压缩包内存耗尽公告；审计建议降级 ONNX Runtime 到 1.21.1。为避免未经兼容验证就破坏本地 OCR/推理，本轮未降级，模型包继续只允许受控来源与摘要验证。
