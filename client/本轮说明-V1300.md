# HashMM V1300 本轮说明

日期：2026-08-09  
主题：Cloud Workspace Runtime 1.0 + App 2.0

## 已完成

- 直接锁定并使用官方 `@cloudflare/computer@0.1.0-alpha.1`，实现 Worker 网关、Durable Object SQLite 工作区、认证、受限 argv、路径/体积/输出边界和单测。
- HashMM 后端新增 Cloudflare Computer provider、owner-scoped 不透明 workspace handle、run/revision 准入、幂等 execution、持久事件与 receipt。
- 桌面/Web 管理状态页接入 provider 配置和真实健康状态；任何 Cloudflare Secret 都不下发客户端。
- App 会话读取改由 owner-checked 后端稳定分页作为规范路径；Supabase Realtime 只触发刷新，旧表直读仅在后端不可用时兼容回退。
- tombstone 升级为 `(deleted_at, conversation_id)` 复合游标；同时间戳跨页不会漏掉删除。
- App“我的”和“对话”的可见 Screen 未改；身份 ViewModel 在登出/切账号时清空旧投影。“工作”新增云环境状态且与桌面接力分离；“今天”继续使用统一 WorkRuntime 事实、行动收件箱和加密 outbox。

## 诚实边界

- 当前没有用户 Cloudflare 账号、API Token、部署域名和生产 Gateway Secret，因此未执行 `wrangler deploy`，也不声称公网 Worker 已上线。
- `@cloudflare/computer` 仍是 Preview；当前接入是 Worker Shell，不等同于完整 Linux 容器。
- 已完成 App JVM 测试和 Debug APK 构建不等于真机验收；弱网、杀进程、切账号、跨端并发和推送唤醒仍需真实设备验证。
- App conversation/message 当前采用稳定分页完整对账，不是统一 workspace change-log；Chat mutation 仍沿用现有链路，只有 WorkRuntime 已具备持久 owner-scoped outbox。
- 既有 V1200 正式安装器仍代表 V1200；只有重新完成 V1300 原生流水线、摘要核对与（如有）签名后，才能把新 EXE 标为 V1300 正式交付物。
