# 交付检查清单

## 事实

- [ ] 最新信息经过联网核验，并写明数据截止时间。
- [ ] 每个关键结论能指向原始来源。
- [ ] 数字、版本、日期、人名与公司名已复核。
- [ ] 推测、评论与传闻没有混入事实段落。
- [ ] 搜索摘要没有被当作原文引用。

## 编辑

- [ ] 标题与正文一致，没有夸大承诺。
- [ ] 开头先给读者价值与主要结论。
- [ ] 重复信息已删除，分类没有为了凑数硬填。
- [ ] 读者能区分“发生了什么”和“这意味着什么”。

## 版式与交付

- [ ] HTML 在 375px 宽度下仍可阅读。
- [ ] 无 emoji、外部脚本、远程字体和不可追溯图片。
- [ ] Markdown 与 HTML 的事实、数字和链接一致。
- [ ] 已列出来源、待确认项和自动化边界。
- [ ] 未经明确确认，没有执行发布、发送或外部写入。
