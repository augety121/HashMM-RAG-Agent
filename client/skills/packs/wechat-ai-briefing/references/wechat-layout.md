# 公众号 HTML 排版约束

## 兼容边界

- 使用单列正文，内容最大宽度 680px。
- 样式以内联 CSS 为主；不依赖外部 CDN、脚本、Web Font、表单或交互组件。
- 不使用 `position: fixed`、复杂渐变、悬浮动画或依赖 `flex` 才能阅读的关键布局。
- 表格最多两层结构；移动端必须可横向滚动或退化为分段列表。
- 正文字号建议 16px，行高 1.75；辅助信息不小于 12px。

## 信息层级

1. 标题和一句话摘要。
2. 数据截止时间与阅读提示。
3. 结论先行的要点区。
4. 分节正文；每节只使用一个核心视觉重点。
5. 来源区和待确认项。

## 颜色与可读性

- 选择一个主色和一个提醒色，其余使用中性色。
- 正文与背景保持高对比度；颜色不能成为唯一的状态表达。
- 警告、传闻和待核验内容必须有文字标签。
- 不使用 emoji 充当导航、状态或装饰图标。

## 可复制交付

- 输出完整 HTML 文档与独立 Markdown。
- HTML 中的链接使用完整 URL。
- 图片必须有替代文本和来源；无法确认版权时不用作商业封面。
