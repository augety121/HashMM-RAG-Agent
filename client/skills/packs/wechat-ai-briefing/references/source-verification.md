# 来源核验

## 候选表

对每条候选内容记录：

| 字段 | 要求 |
| --- | --- |
| 主题 | 一句话说明发生了什么 |
| 原始来源 | 厂商公告、论文、代码仓库、监管文件或当事人声明 |
| URL | 可直接打开的原文链接 |
| 发布时间 | 带时区；无法确认时写“未确认” |
| 事实句 | 只写原文能够支持的内容 |
| 第二来源 | 独立来源；没有时写“单一来源” |
| 状态 | 已核验 / 待核验 / 排除 |
| 风险 | 时间不明、二手转述、标题夸张、数据口径不一致等 |

## 来源优先级

1. 官方公告、官方文档、论文、代码仓库发行记录、监管文件。
2. 当事人可验证的公开声明。
3. 有编辑责任和原文链接的专业媒体。
4. 聚合站、社交媒体转述和搜索摘要只能作为线索。

## 时间窗

- 日报默认只收录最近 24 小时内首次发布或发生实质更新的事项。
- 旧事件的新评论不算新事件；旧文重发不算新发布。
- 跨时区时写明“数据截至 YYYY-MM-DD HH:mm（时区）”。
- 无法确认发布时间的内容不得伪装成当日新闻。

## 冲突处理

- 来源冲突时并列说明各方口径，不擅自裁决。
- 数字口径不一致时标出币种、时间段、是否含税、样本范围等差异。
- 删除结论不会破坏文章主线时，宁可删除也不要猜测。
