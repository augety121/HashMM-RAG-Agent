# 对比 / 榜单 —— 配方

**读者一眼要得到**：候选有谁 → 按什么标准比 → 赢家是谁、为什么。

## 区块顺序
1. 页头：标题=选型问题，副题=直接点名建议赢家。
2. 「需要你拍板」：是否采纳赢家；有一票否决项（价格/合规）单独列出。
3. 赢家卡 `wc-card` + `wc-badge accent`：为什么是它，2–3 句。
4. 对比表 `wc-table`：候选为列、标准为行；单元格写事实值不写"好/差"；
   最优值可用 `wc-badge success` 点亮，但**必须在表下配 `wc-legend` 图例**。
5. 淘汰名单：一行一个 + 淘汰原因（免得读者问"为什么没考虑 X"）。
6. 回喂 composer：chips 预置"采纳 <赢家>""按 <标准> 重新加权比一次"。

## 红线
- 标准 ≤6 条且每条都影响结论；凑数标准删掉。
- 数据来源写进 meta 行；引用外部结论标注出处日期。

## V216 组件
- 候选 ≥4 或读者会按不同标准看时，表格加 `data-wc-sort`（表头可点排序，数字列自动数值序）。
- 数值列可配 `wc-trend` 标相对基线的升降；排序状态由 CSS ↑/↓ 指示，无需图例。
