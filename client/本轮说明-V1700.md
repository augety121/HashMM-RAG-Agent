# HashMM V1700 本轮说明

## 版本组合

- Backend/SDK：V1700 / 1.7.0
- Desktop、WebUI、MCP、Native Installer：8.0.0
- Android：5.0.0（versionCode 170）
- 跨端同步协议：hashmm.sync.v2

## 已实现

1. App 在拉取对话前调用带 Supabase access token 的 `/api/client/bootstrap`，核对项目标识和用户 UUID 指纹。
2. Remote Config 只有成功读取并通过 URL 校验后才写成功时间；失败采用有界退避，不再沉默六小时。
3. App 保留账号隔离的最后成功对话快照，明确区分真实空列表、离线、身份过期、项目不匹配和服务器版本不兼容。
4. App 历史抽屉、执行方式和直连持久化回执完成语义与界面收敛。
5. 桌面项目与最近保持唯一归属；悬停操作不再改变行几何；管理后台顶部装饰盾牌移除。

## 明确边界

- QQ 登录没有实现，也没有保存用户提供的 QQ OpenID。
- `/api/livez` 只证明传输可达；只有 `/api/client/bootstrap` 成功才证明账号已连接。
- 手机快速回答未取得后端写入回执时，只保存在账号隔离本地副本并等待重投，不宣称已进入云端工作区。
- Windows EXE 的 SHA-256 只能证明构建产物一致性；没有 Authenticode 证书时不能声明发布者身份已验证。
