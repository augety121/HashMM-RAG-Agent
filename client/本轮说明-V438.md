# HashMM V438 本轮说明

本轮不是增加九个彼此割裂的页面，而是把 V429–V438 收敛成一条可验证的长任务能力链。Chat、桌面工作画布和 Android 工作画布读取同一个 owner-bound WorkRuntime 投影。

## 已完成

- V429：WorkKernel 控制事件使用幂等事件入口；离线控制 outbox 只保存命令元数据；Provider 能力在调用前形成确定性契约。
- V430：恢复能力只依据实际上下文或执行检查点；没有检查点时不显示“可恢复”，也不声称支持自动回滚。
- V431：公开上下文预算、已用 token、剩余预算、压力和压缩事实；不把检索正文、上传正文或提示词持久化到工作投影。
- V432：把成功条件与完成门的检查及证据引用确定性对齐，区分通过、失败和待确认。
- V433：Artifact 使用内容哈希、generation 和核验状态判断新鲜度；过期结果会阻断交付。
- V434：多 Agent 投影展示实际拓扑、状态、阻断分支、并行净收益和估算轮数；分支不共享原始上下文正文。
- V435：权限投影公开审批模式、网络模式、执行凭证和不可逆副作用；投影不能扩大权限。
- V436：Agent 模式明确要求工具调用能力；Provider 缺少声明能力时形成不兼容阻断，不能以模型文字绕过。
- V437：跨端同步使用 owner、run revision、事件 cursor、change cursor 和 generation 构造指纹；旧桌面缓存缺少 assurance 契约时会重新向服务端核验。
- V438：交付门统一检查完成回执、验收条件、Artifact 新鲜度、Agent 分支、审批、Provider 契约和执行凭证；只有无阻断且完成回执允许时才显示“具备交付条件”。
- 修复写文件副作用幂等键未绑定用户与会话的问题，防止同名同内容文件跨工作区误命中历史成功。
- Android App 解析并展示同一份交付准备度，不再把桌面诊断页面原样搬到手机。

## 安全边界

- 工作 assurance 是只读投影，不能执行工具、自动审批、扩大网络或文件权限。
- 模型自评、页面文案和状态文本都不能作为完成证据。
- 原始提示词、检索正文、文件正文、工具参数、令牌和密钥不会进入 assurance。
- 缺失与越权对象仍由 API 返回不可枚举的相同结果。
