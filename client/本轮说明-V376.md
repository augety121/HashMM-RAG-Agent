# HashMM V376 本轮说明

日期：2026-07-22

## 结果

本轮首先修复日志中已经被证实的文档工坊缺陷：设计任务生成了 HTML，但旧实现把包含斜杠的标题直接拼进文件名，写入失败后仍返回 200，并把整段 HTML 当成“未指定会话”的文本展示。V376 现在把产物绑定到原会话，执行会话所有权检查、安全命名、工作区边界检查和原子落盘；失败明确报错，成功返回结构化 Artifact 并由桌面端或 App 打开。

App 审计不以“页面存在”为完成标准。文档工坊、智能体工坊、总控中枢、知识图谱、画布保存和手机取文件轮询均补齐真实数据源、动作结果、错误态、缓存保留和重试边界。详细矩阵见 `docs/audits/APP-PAGE-CAPABILITY-AUDIT-V376.md`；RAG 与面试实战资料的已实现/待实现边界见 `docs/audits/RAG-INTERVIEW-GAP-MATRIX-V376.md`。

## 明确限制

- Windows 安装器当前 Authenticode 状态为 `NotSigned`。SHA-256 只能证明完整性，不能替代发布者身份；公开分发前必须配置受信任代码签名证书并启用强制签名。
- Android Release APK 尚未配置产品签名密钥，所以本轮交付的是经过测试且可安装的 debug-signed APK，不能冒充商店正式包。
- 服务器日志仍提示默认管理员密码风险。部署前必须替换默认密码，并轮换任何曾暴露的 API key、JWT 或 service-role 凭据。
- App 是桌面工作的伴随入口：审批、选择方向、查看进度和发起工作可以移动完成；本地文件、浏览器和 Computer Use 的特权副作用仍必须由在线桌面执行器执行，不能用 App 页面假装本机已执行。
