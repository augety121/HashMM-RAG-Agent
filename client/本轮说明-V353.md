# HashMM V353 本轮说明

日期：2026-07-19

## 本轮目标

把共享浏览器、画布和多 Agent 收回同一条 Chat 工作流：网页在右栏真实打开，产物在右栏持续迭代，子任务在线程视图中可检查并把结果回传主对话。所有“已打开、已执行、已完成”只由真实 DOM、IPC、服务端状态或测试输出证明。

## Chat 右栏浏览器

1. 回答中的 Markdown 链接和裸 `http(s)` URL 都带统一的受控链接标记，左键进入 Chat 右栏；Ctrl/Shift/中键仍保留用户的浏览器原生选择。
2. 左栏“共享浏览器”改为面向用户的“浏览器”，点击后回到 Chat 右栏；输入框的浏览器模式同样打开该右栏。
3. 右栏提供地址栏、前进、后退、刷新/停止、页面标题、加载错误和系统浏览器兜底。
4. “交给 Agent”只把 URL 和明确任务送回 Chat Browser Agent；不会把尚未真实读取的页面文字冒充证据。
5. Electron 安全边界：
   - 固定 `persist:browser-use` 隔离会话分区；
   - 首站显式授权，未知跨站跳转与弹窗默认阻止；
   - `nodeIntegration=false`、`contextIsolation=true`、`sandbox=true`，删除任意 preload；
   - 只新增窄 IPC `browser:authorizeNavigation`，继续受 `ipc-guard` 的 `browser:*` 敏感分类保护。

## Artifact 画布

- 保留并收口已有真实能力：HTML 沙箱预览、源码、就地编辑、停笔自动保存、互斥编辑锁、跨会话版本、历史与 latest 对比、复制/下载、发布、模板、划选提问和定向修改。
- 右栏增加本会话产物栈，最多保留 8 个最近打开的画布/代码/文件，可直接切换，不再被最后一个产物覆盖。
- “AI 续写”改成更明确的“让 Agent 修改”；当前版本通过受限 FeatureContext 回到主 Chat，用户确认后再发送。
- 新建画布在线时立即落入当前会话文件并打开右栏；未登录、离线或后端暂不可达时也会先打开可编辑的本地 Artifact 草稿，不再退化成只向输入框回填一句提示词。
- 本地草稿编辑会继续更新本地权威内容；恢复连接后可通过 Chat/Agent 走正常会话文件链路落盘。未落盘前不伪装可下载或已发布状态。

## 多 Agent

- 沿用真实团队执行器与 owner-scoped 状态接口，不另造演示数据。
- 每个角色现在有稳定的 `agent_id`、`thread_id`、`parent_thread_id` 和创建/开始/结束时间。
- Chat 卡片与右栏统一显示“子任务线程”，可展开查看任务、Active/Done、耗时、失败和返回主任务的结果。
- 主任务负责目标与最终交付；子任务在独立上下文中完成有界工作；团队仍支持协作式停止和带 `retry_of` 的终态重试。
- 当前层级保持一层父子关系；没有加入子 Agent 递归拉起子 Agent，避免无界成本、权限漂移和写冲突。

## 官方校准

- OpenAI Codex：采用主任务保持决策/交付、子任务隔离高噪声探索、Active/Done 可检查、停止/重试与权限继承的产品心智。
- Anthropic Artifacts：采用对话旁独立工作区、多产物切换、预览/源码、编辑迭代、版本、复制/下载与分享。
- Claude Code subagents：采用独立上下文、任务/工具边界和结果回传；没有把 agent teams 的对等通信强行套进当前中心化团队。

## 明确限制

- 部分站点设置 `X-Frame-Options` 不影响 Electron `webview`，但站点自身的登录、验证码和风控仍需用户完成；HashMM 不绕过这些限制。
- 当前右栏浏览器与 Browser Agent 共用隔离登录分区，但页面渲染 WebContents 与自动化执行 WebContents 仍是两个沙箱实例；Agent 接手时会按当前 URL 重新打开并读取，不能把右栏未读取的视觉状态当成执行证据。
- 子任务线程公开的是任务、状态、耗时和最终返回，不公开模型私有思维链。运行中的模型调用不能硬杀；停止请求会在调用安全返回后丢弃结果。
- 本轮没有生成正式签名 Native EXE；正式安装包仍必须由 `installer-native/build-all.bat` 构建并核验 Authenticode、SHA-256 与 release metadata。
