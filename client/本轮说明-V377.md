# HashMM V377 本轮说明

日期：2026-07-22

## 结果

本轮没有把“页面能打开”当成 Agent 能力完成。多 Agent 团队现在为每个角色建立真实 `AgentSession` 和独立执行作用域，团队停止会向活跃子会话发出中断请求；持久化与跨端事件只保存有界运行事实，不保存原始工具参数、凭据或长正文。桌面端右侧运行面板和 App 运行轨迹读取同一条服务端会话证据链。

Graph Engineering 继续下沉到检索运行协议。系统记录图扩展前后证据数量、候选关系、缺失节点和被 ACL 拒绝的节点，并在扩展后重新做权限校验；只有可回溯到原始知识块的证据能够进入上下文。工具执行结果也统一为结构化成功/失败契约，避免“报错文本非空就被判定为成功”。详细参考边界见 `docs/reference-audit-V377.md`。

## 明确限制

- 本轮没有生成新的 Windows 安装程序，因此不把源码发布闸门等同于安装器发布成功。需要发布桌面安装器时，仍必须执行 `installer-native/build-all.bat` 的完整流程，并核对 EXE、`.sha256` 与 `.release.json` 三方一致。
- Android 交付物为 debug-signed APK，不是商店正式签名包。
- 正在进行的单次模型或外部工具调用无法被进程内标志强制终止；中断在安全检查点生效，界面明确显示这一边界，不伪造“已立即停止”。
- Graph 扩展只能增加当前用户可访问、可回溯到原始知识块的证据；图中没有原文或被 ACL 拒绝的节点只计入诊断，不会注入上下文。
- App 是桌面工作的伴随入口。本地文件、浏览器、Computer Use 等特权副作用必须由同账号在线桌面执行器执行，App 不会把服务端有记录误写成手机本地已经执行。
