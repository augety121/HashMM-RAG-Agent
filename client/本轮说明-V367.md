# HashMM V367 本轮说明

## 目标

修复桌面端模型服务兼容响应导致的崩溃，让统一检查器按任务打开而不是启动即遮挡 Chat，并把知识图谱真实接入 RAG 证据、桌面端和 App，而不是只显示实体关系页面。

## 已完成

- 模型列表兼容裸数组与 `{models}`，厂商清单兼容裸数组与 `{providers}`；异常对象和缺字段响应归一为空列表，快速模型选择与管理后台共用同一边界。
- 新桌面进程始终以关闭的统一检查器进入；浏览器、文件、画布和上下文操作仍会为当前任务显式打开检查器。
- `KGRetriever` 输出查询局部的实体、关系和 `chunk_id` 支撑；Graph Engineering 将其回接到原始索引切片、去重、限量并写入 Chat 来源。
- 桌面端来源与右侧上下文显示图关联实体/关系，管理后台“图工程”展示后端真实就绪状态；App 来源卡解析同一 `method=graph_evidence` 协议。
- 运行清单记录图证据数量和证据保留策略，便于质量评测与问题复盘。

## 权限与正确性

- 文档 ACL 在初始检索、图证据扩展和最终提示词边界重复执行；权限过滤异常时返回空结果，不回退到未过滤结果。
- 有显式文档允许列表时，不注入可能跨文档聚合的实体/关系摘要，只允许经过 ACL 的原始证据切片进入模型上下文。
- 图关联标签只是来源解释，不是事实证明；最终回答仍须引用原始证据，模型生成内容不能反向作为检索或执行成功的证据。

## 明确限制

- 当前 Graph Engineering 是查询时证据图，不是完整的任务图、权限委托图或 Agent 自我强化系统；后续图层必须经过数据模型、权限与评测设计后再进入主链路。
- 当前普通检索、KG 和图证据仍依赖已有索引质量；没有构建 KG 或没有真实 `source_ids` 时会安全退化，不伪造图证据。
- Windows 安装器 Authenticode 状态为 `NotSigned`。SHA-256 能证明完整性，不能替代发布者身份签名。
