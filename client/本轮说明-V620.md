# HashMM V611–V620 本轮说明

日期：2026-07-28  
Backend：V620  
Desktop / MCP / Native：1.38.0

## 本轮完成

### 1. 用户工作空间重构

- 项目、资料库、画布、协作、我的与设备接力统一为“对象列表 + 当前对象详情 + 回到 Chat”的任务结构。
- 项目围绕目标、交付物、完成条件和状态组织，不再向普通用户暴露 Agent 编排参数。
- 资料库支持文件类型筛选、资料选择篮、同一 Chat 内提问/比较/制作成果。
- 画布成为与原对话关联的长期成果对象；编辑、来源、版本和 Agent 修改继续使用共用成果侧栏。
- 协作使用“说明工作、确认分工、查看结果”三步，并继续调用现有预览、启动、状态、停止和重试接口。
- “新对话”现在会退出项目、插件、画布等工作空间并清理上轮工作方式，修复侧栏高亮与主内容不同步。

### 2. OKF 知识包

- 新增账号隔离的 OKF ZIP 预览、明确确认导入、知识索引、列表和导出接口。
- 校验路径穿越、符号链接、加密项、UTF-8、文件数量、单文件和总解压体积。
- 非保留 Markdown 必须声明 `type`；未知类型和扩展字段保留，缺少来源或失效链接以警告呈现。
- 支持 `provenance`、`generated`、`verified`、`status`、`stale_after` 等信任信号；计算声明只作为元数据，不执行其中内容。
- 导入前预览在服务端按账号暂存并设置有效期，确认导入后才写入 owner-scoped 数据和检索索引。

### 3. 搜索服务融合 Chat

- 新增按账号配置的豆包搜索兼容服务：API Key 在服务端加密保存，桌面端只能读取遮盖状态。
- 支持官方兼容路径和用户自定义 HTTPS/localhost 基址、结果数、摘要长度、认证头名称。
- 搜索结果进入现有 `web_search` 工具链，继续经过来源结构化、缓存、审计和 Chat 证据表达。
- 插件中心提供保存、停用、移除和“在 Chat 中试用”入口；未配置密钥时不会伪装成可用。

### 4. 插件与运行时门禁

- 插件中心统一呈现内置工作能力、个人工作方法、联网搜索和受信任外部插件。
- `cryptography` 与 `PyYAML` 纳入正式运行时依赖；运行时构建、桌面启动校验和发行门禁都会实际导入二者。
- 生产环境缺少加密库时仍失败关闭，不降级为等同明文的 XOR 存储。
- 能力装配改为工具粒度的失败关闭：缺少 schema 或执行器的工具不会进入 Chat，但同模块其他已完整接通能力不再被连带隐藏。
