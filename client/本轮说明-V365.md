# HashMM V365 本轮说明

本轮不是新增孤立页面，而是继续把画布、多 Agent、Chat 长任务、Browser Use、Computer Use、MCP 与 Hook 收拢到同一条可审计执行链。实现参考了用户提供的本地 `D:\sheji\codex-main` 可验证源码机制和《大模型应用!算法学习路线+八股+面试实战4.md》中关于工具调用、规划轨迹、评测与故障边界的内容；未把外部项目的私有实现或模型宣传当成事实。

## 已完成

- **统一 Hook 执行边界**：动态 MCP、自定义工具、主 Agent 与 Worker 子 Agent 均进入中央工具执行器；`PreToolUse` 的风险、租户、计划和治理钩子关键失败时拒绝执行，观察型钩子失败不阻断，并记录有界 `PreToolUse`、`PostToolUse`、`PreCompact`、`SubagentStop` 轨迹。
- **MCP 真实协议闭环**：补齐初始化、`initialized` 通知、会话 ID、分页、SSE/JSON 解析、响应 ID 校验、工具 schema/annotations 归一化、健康状态、错误信息和凭据脱敏；动态 MCP 工具继续采用保守权限而非默认只读。
- **多 Agent 可恢复状态**：团队、角色、证据和轨迹使用原子有界持久化；后端重启时残留的运行态会明确收敛为失败并给出恢复原因，不会虚构“模型调用已经续跑”。子 Agent 停止也进入统一 Hook 审计。
- **Chat 长任务租约**：桌面任务执行期间每 15 秒续租，后端只允许任务属主为已领取任务续租；避免超过 10 分钟的 Browser/Computer 长任务被错误回收后重复执行副作用。
- **Browser Use / Computer Use 边界**：全部浏览器页面内容均按外部不可信数据封装，不再只处理命中可疑词的页面；畸形 JSON、数组或非对象工具参数会返回可修复错误，不会静默变成空参数后继续执行。
- **画布 Artifact 隔离**：版本历史以“会话 + 文件名”作为作用域，同名画布不会跨 Chat 混合版本；新增回归测试固定这一行为。
- **产品可见性**：Hook 运行结果进入流式记录，并在 Chat 消息、Agent 日志和右侧上下文中展示，使失败、拒绝和实际执行证据可查。

## 明确限制

- 进程重启无法恢复已经在第三方模型服务内部执行的调用；V365 选择把残留角色标为失败并保留证据，用户可安全重试。
- MCP 本轮强化的是后端 Streamable HTTP/SSE 路径，不宣称已经覆盖所有第三方 stdio 服务器差异。
- Electron 内嵌浏览器使用 Chromium 能力，但目标站点仍可能通过 CSP、登录策略或机器人防护限制自动化；不得通过放宽全局安全策略绕过。
- 安装器完整性已由 SHA-256 三方一致证明，但当前 Authenticode 状态为 `NotSigned`，尚不能提供发布者身份保证。
