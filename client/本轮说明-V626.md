# 本轮说明 V626

## 联网搜索统一为一份账号配置

- 插件中心“联网搜索”和管理后台“检索设置”现在复用同一个账号级设置组件、同一组 owner-bound API、同一份服务端密钥记录和同一条真实连接测试链路。
- 豆包 API Key 只提交给服务端密钥存储；前端只读取脱敏状态，不把密钥写入源码、浏览器存储、日志、测试、发行说明或发布包。
- 普通用户默认只看到启用状态、凭据、返回数量、摘要长度和“在 Chat 中试用”；兼容地址、API 版本、检索范围与授权级别收进高级设置。
- 管理后台保留独立的“平台检索兜底”，用于 Serper、Bing、Tavily 等管理员级全局策略，避免把个人豆包凭据和平台兜底混成同一配置。
- 未登录、权限不足、旧服务器缺少接口、连接失败和真实测试结果分别呈现；旧服务器返回 404 时明确提示升级服务器包，不显示原始调试错误。

## 设备接力展示真实设备事实

- 页面保留“设备列表 + 当前设备详情”的单一工作区，本机、App 接力和账号所属执行器在同一列表切换。
- 执行器接口失败不再静默伪装为“没有设备”，而是显示可重试的读取状态。
- 当前设备详情显示实际在线状态、最后上报、今日完成、今日失败和最近领取时间；进入桌面、文件与连接仍受设备在线状态、短期授权和审计规则约束。
- 远程桌面、文件、RDP、Moonlight、EasyTier、TURN 与安全策略继续保留在对应下一层，不在首页向普通用户堆叠实现名词。

## 自动任务成为可继续工作的工作台

- 页面重构为“任务/模板列表 + 创建或任务详情”，继续复用真实计划任务 API，而不是静态样例。
- 支持创建、启停、立即运行、删除和刷新，并显示目标对话、下次执行、最近执行、运行次数、回写位置和最近结果。
- 每日简报、资料更新摘要和知识健康检查只作为可编辑起点；用户确认前不会自动创建或执行。
- 加载和执行错误不再被吞掉，未登录或服务端暂不可用时不会伪造任务和成功状态。

## 启动与版本一致性

- Backend：V626。
- Desktop/MCP/Native source：1.38.6。
- 公共启动器的诊断标题改为读取后端真实 `RELEASE`，不再出现诊断版本与运行版本错位。

## 仍需真实环境验收

- 设备接力的实际 App 账号、远端执行器地址解析、公网多设备、对称 NAT、自有 TURN、RDP/Moonlight 和 24 小时稳定性仍需在真实部署环境验收。
- 本地浏览器验证环境没有登录真实设备账号，因此设备页的多设备列表与远程连接没有写成“已实测通过”。
- 豆包搜索需要部署 V626 后，用已轮换的新密钥重新保存并执行连接测试；本地测试没有使用或保存聊天中公开过的密钥。
- 当前安装器经 Windows `Get-AuthenticodeSignature` 核验为 `NotSigned`。SHA-256 只能证明文件完整性，不能替代受信任发布者身份；公开分发前仍应完成 Authenticode 签名。
- 公网部署必须使用 HTTPS/WSS；HTTP 环境不能作为登录令牌和远程接力的正式安全验收。
