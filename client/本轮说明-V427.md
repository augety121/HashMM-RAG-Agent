# HashMM V427 本轮说明

日期：2026-07-26

V427 不是 UI 演示版更新，而是对 Chat/RAG/工具执行链的确定性收口：

- 写入工具的幂等预留失败时 fail-closed，不再把未知状态降级成可重试的“未执行”；
- 幂等结果提交失败时返回 `uncertain / idempotency_commit_unavailable`，明确提示外部写入可能已经发生，禁止自动重试；
- Python 工具链移除生产路径中的伪代码审查输出，仅保留可复现的 AST 语法检查，并以 `independent_verify` trace 返回证据；
- 编译器/验证器异常不再当作通过，验证不可用会返回失败；
- Agentic RAG 记录检索、生成和编排异常，`/api/chat/agentic` 将错误作为结构化 `errors` 返回，避免空结果被误当作有依据的答案；
- 对上述行为增加幂等、检索异常和工具链验证回归测试。
- 发布前回归：后端 `1426 passed, 8 skipped`（2 条既有依赖警告）；前端 `123 passed`、typecheck 与 Next production build 通过；桌面 Node `70 passed`；release source gate 通过。
