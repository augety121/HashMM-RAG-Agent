# HashMM V354 本轮说明

日期：2026-07-19  
范围：Desktop / Frontend / Backend；App 本轮未改动  
版本：Backend `V354`，Desktop / MCP / Native source `1.17.10`

## 本轮完成

### 1. 右栏“系统”身份修复

- `contextInspect` 请求现在携带当前会话的 Bearer token，已登录用户不再被错误显示为“未登录”。
- GET 在途请求去重键加入认证身份，切换账号时不会复用另一个账号的请求结果。
- 新增回归测试，覆盖认证头和同一 URL、不同账号的请求隔离。

### 2. Chat 右栏嵌入浏览器修复

- 修复 WebView 尚未挂载就调用 `loadURL` 导致的运行错误：首次地址通过 `src` 完成 guest attach，收到 `dom-ready` 后才启用 `loadURL`、刷新和前进后退。
- “使用系统浏览器打开”接入 React 实际使用的 `hashmmDesktop` preload bridge；主进程只接受不含账号密码的 HTTP/HTTPS 地址，并等待系统打开结果后再回报。
- 浏览器任务继续留在当前 Chat 的统一右栏，不再自动打开割裂的独立 Cockpit。
- “交给 Agent”只传递当前 URL、页面标题和“尚未由 Agent 读取”的事实；不会把用户可见页面冒充为已取证内容。

### 3. 顶栏布局修复

- 右栏打开时，中央 Chat 顶栏不再错误预留 Windows 窗口控制区宽度。
- 窗口级安全间距由真正贴近窗口右边缘的统一检查器承担，模型选择器和相邻操作按钮回到正确位置。

### 4. Browser Use、Computer Use 回到 Chat 主链

- Browser Use 由 Chat 打开统一右栏；已有 URL 时沿用当前页面，否则打开安全的默认入口。
- Browser/文件/画布等 FeatureContext 现在能进入本地 Computer Use 任务。
- FeatureContext 使用长度受限、转义后的 JSON，并放入明确的不可信边界；外部页面、文件和产物内容只能作为数据，不能覆盖任务、权限或安全规则。
- Computer Use 成功后才消费附加上下文；失败时保留，方便用户修正后重试。

### 5. Artifact 与多 Agent 校准

- Artifact 延续统一右栏中的真实编辑、自动保存、版本、预览、差异、下载/发布、多产物切换和“让 Agent 修改”链路，本轮没有把演示状态写成已完成能力。
- 多 Agent 延续“主任务—独立子任务线程—状态与结果回传”模型，保留稳定线程标识、运行状态、停止与终态重试；不展示或声称保存模型私有思维过程。
- 当前仍是一层受控子任务编排，不宣称具备 Claude Code agent teams 的点对点通信或完整 worktree 隔离。

## 安全边界

- 外部网页、网页文本、上传文件和工具输出均视为不可信数据。
- 系统浏览器 IPC 仅允许 HTTP/HTTPS，拒绝携带 URL 用户名或密码。
- Browser Use 与 Computer Use 的高影响动作仍需经过既有权限、审计和人工确认机制。
- Electron WebView 使用隔离持久分区，不向访客页暴露 Node、preload 或宿主 IPC。

## 官方机制校准

- Electron WebView 文档：方法应在元素加载完成后使用；Electron 同时提示该标签的稳定性风险，后续应评估迁移到 `WebContentsView`。
  - https://www.electronjs.org/docs/latest/api/webview-tag
- OpenAI Computer Use：隔离浏览器/虚拟机、域名允许清单、不可信页面边界和高影响动作人工确认。
  - https://developers.openai.com/api/docs/guides/tools-computer-use
- OpenAI Codex subagents：独立 agent 线程、委派、等待/汇总和状态检查。
  - https://learn.chatgpt.com/docs/agent-configuration/subagents
- Anthropic Artifacts：右侧独立产物、编辑、版本、源码、复制/下载和多产物切换。
  - https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them
- Claude Code agents：subagents、agent teams 和 worktree 工作流属于不同层次的并行机制。
  - https://code.claude.com/docs/en/agents

## 已知限制

- 当前嵌入浏览器仍基于 Electron WebView；本轮修复其挂载时序和宿主桥接，但长期应评估 `WebContentsView` 迁移。
- 用户可见 WebView 与 Browser Agent 使用相同隔离分区策略，但不是同一个 WebContents；Agent 接管时会按 URL 重新读取并生成自己的证据。
- 登录、验证码、支付、提交和其他高影响网页动作不会被描述为无人值守保证。
- App 本轮未改动，也未声称已经同步 Desktop 的本轮 UI 修复。
- 本轮只完成 source release gate，没有生成或验收 Authenticode 签名的最终安装 EXE。
