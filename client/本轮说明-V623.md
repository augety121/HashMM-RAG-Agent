# 本轮说明 V623

## 面向用户的导航与工作区

- 左侧一级导航只保留“今天、资料库、插件、设备接力”；项目与最近对话继续作为可切换的本地工作记录，“我的”不再占用一级导航。
- 画布与协作仍支持旧入口和深链接，但页面顶部提供“回到对话”，明确它们是当前 Chat 的准备/验收工作区，不是另一套孤立会话。
- 今天、资料库、项目、成果、设备接力统一使用工作区对象列表/详情布局，状态徽标只显示服务端快照或明确的连接状态。
- 设备接力与成果页显示服务端权威的在线设备数和可验收成果数，不用静态演示数字。

## Chat 与能力设置

- Chat 输入框继续承载画布模板与多智能体面板；启动后沿用当前 `sid`，结果回到原会话。
- 设置新增“浏览器与电脑”能力页，用户可以控制浏览器、电脑操作、画布、多智能体的入口显示，并从设置直接回到当前 Chat。
- 插件中心的内置能力、外部插件、个人工作方法和联网搜索配置均保留真实 API 状态；未接通时显示不可用原因，不伪装成可用。
