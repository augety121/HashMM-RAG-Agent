# HashMM V2800 本轮说明

## 已实现

- 远程连接改为严格的审批后媒体协商：票据签发失败即关闭会话，旧异步任务不能覆盖新会话，兼容预览增加宿主启动回执。
- Android 在远程控制面 401 时单次刷新 Supabase 会话，并用新令牌重建 bootstrap、票据和 WSS；失败后才要求重新登录。
- Chat 拖放支持文件夹递归、真实字节进度、三并发、取消、失败重试、成功回执复用和按 Chat 隔离的附件草稿。
- 普通用户设置新增 Provider Fabric 工作区；Sub2API/兼容网关可创建、检查、配置模型通道、预演路由并显式用于 Chat。
- Android“我的 API 与模型”补充 Sub2API 入口；桌面和 App 均不把上游密钥回显或与对外 API Key 混用。
- 统一版本为 Product/API `28.0.0`、Backend `V2800 / 2.8.0`、Desktop/Installer `17.0.0`、Android `12.0.0 (280)`。
