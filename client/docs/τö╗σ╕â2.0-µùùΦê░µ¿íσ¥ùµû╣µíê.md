# 工作画布 2.0 —— 从演示到旗舰模块（V222 落地 P0，含完整路线）

## 定位（把你的想法补全成一句话）
**画布 = 新手也能上手 agent 的"可视化工作台"：agent 的产出落在画布上，
用户能直接看、直接改、划哪问哪；主对话负责"创作与推进"，画布负责"落地与打磨"，
两条通道各司其职、互不打扰。** 这个"产物即协作界面"的闭环，正是大厂们缺的那块。

## 双通道模型（你说的"和主问答不同、偏谷歌搜索那种"）
- **主对话**（/api/chat/stream）：重链路——检索、工具、记忆、规划；负责"往前创作"。
- **就地小问答**（/api/canvas/ask，V222 新增）：轻链路——只带"选中片段 + 前后 200 字 + 一个问题"，
  quick_call 单轮小 token（≤400），**不进会话历史**。答案气泡里可一键「转主对话深挖」——
  小问题就地消化，值得深挖的才升级，token 花在刀刃上。

## V222 已落地（P0 三件套）
1. **点击即开**：输入框「画布」chip 点击=右栏立即新建一张可编辑空白画布
   （无会话自动建；模板经新端点 `PUT /api/conversations/{id}/files/{名}` 落盘；老后端自动
   退回指令模板，不白点）。
2. **选中即问**：画布里划选任意文字/代码 → 浮出「问一下 ✦」→ 右栏内气泡出答案
   （复制 / 转主对话深挖）。协议 `wc:ask{text,context}`；后端 `/api/canvas/ask`。
3. **就地编辑（用户改的 agent 能看到）**：工具条「编辑」开关 → 画布正文直接可写，
   停笔 1.2 秒自动 `wc:save` 整页回写**原文件**（原子替换）+ 自动进版本历史（v1…vN 落盘链
   复用 V217）。文件即真相源——agent 下一轮读到的就是你改过的版本，接着创作即闭环。
   协议：宿主→画布 `wc:edit{on}` / `wc:flush`；画布→宿主 `wc:save{html}`。

## 协议总表（V222 共七条，向后兼容 V215+ 画布）
画布→宿主：wc:ready · wc:prompt · **wc:ask** · **wc:save**
宿主→画布：wc:theme · **wc:edit** · **wc:flush**
运行时双源同步：技能包 `assets/canvas.js`（agent 生成的完整画布）与
`frontend-next/lib/canvasTemplate.ts` 迷你运行时（点击即开的空白画布），注释互指。

## 安全红线（一条没松）
iframe 仍 sandbox=allow-scripts 无同源；写入端点与读取同套防线（require_conv_access +
basename + 2MB + 原子写 + 扩展名白名单 .html/.htm/.svg/.md/.txt/.json/.csv）；
小问答限长（问 500 / 上下文 2000）且不落会话；画布内零 localStorage。

## 发布与协作可见性（V226 落地，对标 Claude Code Artifacts）
架构公式照搬并升级：**Session Context + 版本链 + Org Viewer = 协作可见性**。
- 工具条「发布」→ 生成组织内私有链接 `/canvas/{id}`（org=所有登录用户 / private=仅自己）。
- **同一链接永远最新版**——且比 Artifacts 的 republish 更进一步：Viewer 直读 latest 文件
  与版本侧车，发布者**编辑保存即全网最新**，republish 动作本身被消灭；Viewer 内可切最近 5 版。
- 只读由架构保证：Viewer 壳不监听任何 wc:* 消息，iframe sandbox=allow-scripts——
  编辑/保存/小问答在 Viewer 侧天然失效，不是样式伪装。
- 轻量审计：发布记录含 views/last_view；停止分享即刻失效。存储为 data/canvas_shares.json
  侧车（v2 迁审计表）。红线沿用：发布前自查不含密钥/未脱敏数据（对标图 4 提示）。

## 路线图（诚实分期）
- **P1（下一轮）**：SVG 画布同链路就地编辑（文本型，白名单已放行）；小问答支持"改写并替换
  选中片段"（wc:apply，把答案直接写回选区）；画布模板库（进度报告/评审/对比三模板一键起）。
- **P2**：PPT/PDF——二进制不做就地改（诚实边界），走"转 HTML 画布编辑 → 导出 pptx/pdf"
  （复用后端既有导出能力）；多人光标（远期）。

## 验收标准（P0）
点击 chip ≤2 秒右栏出画布；划选→答案首字 ≤5 秒（quick 通道）；编辑停笔后
「已保存」提示 + 版本 chips 增一版；重开会话画布内容=最后编辑版。
