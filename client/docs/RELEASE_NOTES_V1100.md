# HashMM V1100 release notes

V1100 fixes the desktop continuity model at the data-contract level. Recent
dates now reflect real content activity; project membership, title edits and
cloud observation no longer rewrite history. Worktrees are bound to a selected
project and a verified device-local Git root. ProjectVault shows desired and
effective paths separately.

New-Chat continuation, Chat mailbox delivery and App/device resume are separate
domains. Plugin administration now distinguishes executable Python trust from
declarative activation, including digest-change invalidation and recoverable
quarantine. The unavailable durable follow-up queue option was removed instead
of being presented as effective.

No Python dependency was added or upgraded. Optional OCR providers remain
environment capabilities discovered at runtime.
