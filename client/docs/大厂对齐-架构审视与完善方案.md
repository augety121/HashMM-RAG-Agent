## 二、本轮已补齐（全部落码、离线测试通过）

### 图3 → 五层指令体系（`project_instructions.py` 重写）
原来只有"单文件就近优先"。现在是完整五层合并注入：
企业级（env/`/etc/hashmm/HASHMM.md`，强制、个人无法覆盖）→ 用户级（`~/.hashmm/HASHMM.md`）→ 项目级（`<根>/HASHMM.md`）→ **规则级**（`.hashmm/rules/*.md`，支持 frontmatter `when:[关键词]` / `globs:[路径]` 条件触发）→ 本地级（`HASHMM.local.md`，不进 Git）。
与图3同款冲突哲学：不整段替换，全部合并进同一上下文并声明裁决规则（更具体/更贴近任务/更靠后优先——认知层软先级；硬约束永远由权限层代码保证）。逐层+总量双截断，空态零变化，永不抛错。测试覆盖：层序/条件命中/合并/截断/空态。

### 图2-① → 文件指纹库（`pipeline/fingerprint.py` 新建 + `ingest.py` 接线）
独立 SQLite `file_fingerprints`（sha256 主键 + filename/size/doc_id/first_seen），SHA256 流式计算。`ingest_file` 入口守卫：同文件重复上传 → 秒回既有 doc_id、status="duplicate"，跳过解析/切块/向量/KG 全流程；doc 目录被手删后指纹自愈失效；`remove_document` 同步清指纹。幂等控制从此闭环。

### 图2-⑤ → Trace JSONL 落盘（`observability.py` 增强）
环形缓冲重启即丢，现在三个汇点（gen_ai_request / tool_call / error）同步追加到 `<DATA_DIR>/trace/agent-YYYYMMDD.jsonl`：按天分文件 + 20MB 轮转，`HASHMM_TRACE_JSONL=0` 可关，`trace_tail(n, kinds)` 供回放/诊断/评测集使用。观测层铁律保持：任何失败不影响请求路径。

### Qoder 对应物 → Session 运维（后端 + 桌面 UI 全链路）
- **Session 动态 Patch**（`api/session_runtime.py` + `routes/session_ops.py`）：`PATCH /api/conversations/{cid}/runtime`，键白名单 model / temperature / system_append / tools_allow / tools_deny，值传 null 删键；下一轮 turn 生效、上下文不丢。消费点三处：Agent 循环（温度/工具过滤/临时指令注入，trace 里可见"运行时补丁生效"）、直答路径（温度/模型偏好/临时指令）。A/B 调 prompt、临时禁掉打转的工具、不重建会话切参数——试错成本降下来。
- **诊断助手**（同路由 `POST .../diagnose`）：自动收集该会话最近 60 条消息（含 thinking/tool_calls）+ 全局最近 300 条 trace；启发式识别 9 类错误模式（超时/限流/鉴权/模型未就绪/工具失败/网络…）+ 5 类停止原因语义（轮数上限/预算耗尽/无进展短路…）+ 失败最多的工具 Top5 + 超慢调用；有 LLM 时再做一次 25s 限时润色；输出结构化 findings + markdown 报告。
- **桌面入口**：后端连接页新增「会话运维」卡（`BackendView.tsx`）——会话下拉/手填 ID、补丁表单（应用/清空）、一键诊断、报告弹层一键复制（直接贴工单/群里）。`lib/api.ts` 新增 4 个函数。

## 三、剩余差距与分阶段路线（按性价比排序）

1. **BM25 持久化确认**：HybridRetriever 的 keyword 源当前由注入的 `keyword_search_fn` 提供——落一个磁盘化倒排（term→tf/idf/doc_length 的 JSON/SQLite，图2-③口径），冷启动免重建。

### P1（两到四周）
