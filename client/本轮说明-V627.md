# 本轮说明 V627

## 目标

这一轮不是增加一段“会写代码”的提示词，而是把长代码、长对话和自动任务接入同一套可恢复、可审计、可验收的工作运行时。方法论来自对用户提供的 7 份长对话记录的结构蒸馏：读取真实状态、先定边界和入口、分阶段执行、把失败当证据、验证后交付、留下可继续工作的交接状态。旧项目内容没有进入产品。

## 长代码与 Harness

- 复杂代码任务会生成确定性工程计划：检查入口/接口/依赖/构建链，实施有界修改，运行定向验证并修复，最后检查差异与全量发布门禁。
- 每个计划步骤有稳定 ID；运行事件只推进与其匹配的步骤，不使用模型自述伪造进度。
- 任务交接保存目标、约束、计划、决定摘要、证据、成果、阻塞、下一步和验证状态，支持进程重启与跨端继续。
- 外部仓库、命令输出和文件内容继续被视为不可信数据；未知工具不会被默认当成只读能力。

## 长对话与上下文压缩

- 压缩检查点升级为长期工作交接结构，保留目标、当前意图、约束、计划、关键决定、证据、成果、阻塞和未完成动作。
- 自动压缩根据模型窗口、输出保留和压力阈值触发，并记录触发方式、原因、压缩前后 token、预算、压力和策略。
- 原始对话消息不会因压缩而删除；恢复只依赖服务端持久化事实，不依赖模型的私有思维过程。
- 对用户可见的是计划、决定摘要、动作、证据和验收；模型私有思维链不存储、不展示。

## 自动任务成为真实长任务

- 每次计划任务执行创建一个 owner-bound WorkRun occurrence，来源绑定任务 ID 与 occurrence ID。
- 运行过程固定为“明确范围、执行、验证、交付”四阶段，阶段状态由运行事件更新。
- 只有真实动作返回后才进入验证；交付回写对话前重新检查会话归属。
- 失败、阻塞和中断不会显示为完成；重试创建新的账号隔离 occurrence，原运行保留作审计记录。
- 桌面端自动任务列表展示最近运行、验证状态、下一步和任务链入口，直接打开统一工作画布。

## 参考边界

- 本地 Codex 源码用于核对公开可观察的持久会话、恢复、转向、压缩事件、计划与运行项分离等工程结构。
- 官方开源游戏与游戏基础设施仓库用于提炼模块边界、平台适配、生命周期、健康检查、指标、测试和发布纪律；没有复制第三方受版权保护的游戏实现或素材。
- V627 不声称复制 Codex/Claude 的内部私有思维链，也不声称模型本身已被重新训练；提升来自 HashMM 自己的运行时、上下文、工具、证据和验证 Harness。
