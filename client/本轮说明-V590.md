# HashMM V581–V590 本轮说明

日期：2026-07-27  
Backend：V590  
Desktop / MCP / Native：1.35.0

## 本轮目标

本轮处理真实桌面验收暴露出的三个断点：插件页面调用不存在的接口、个人 Skills 只存在于深层设置而难以发现、问答栏把常用工作方式藏进占据空间的大面板。同时继续收敛画布工具栏，让插件、Skills、资料范围和画布都回到当前 Chat 的工作链，而不是成为孤立展示页。

## 已实现

### 真实插件与能力中心

- 前端插件请求改用后端实际挂载的 `/api/plugins` 路由；服务端为 V580 客户端保留隐藏的 `/api/system/plugins` 兼容路由，避免新旧桌面与服务器交叉升级时再次出现 `no such API route`。
- 页面把“内置工作能力”和“外部插件”分开：内置卡片来自 `/api/runtime/capabilities` 的本次运行状态，外部插件来自经过清单校验、管理员信任和加载的真实插件目录。
- 内置能力卡片进入现有 Chat 工作方式或真实工作页；不会用静态市场卡片把未安装、未授权或未接通的第三方服务标成可用。
- 外部插件继续显示工具、权限、摘要、加载错误与当前 Chat 选择；普通用户不能借插件页扩大权限，管理员信任仍要求精确 SHA-256。

### 用户可发现的个人 Skills

- 插件中心增加“技能”页签并复用现有个人 Skills 管理能力，系统 Skill 和个人 Skill 可在同一用户入口查看。
- 保留 ZIP、公开 HTTPS、GitHub、Codex、Claude Code 与兼容 Agent Skills 目录导入，以及账号级启停、删除和渐进式 Chat 注入。
- 导入内容继续按不可信指令数据处理，不执行附带脚本，也不会自动获得文件、网络、工具或管理员权限。

### 问答栏与资料范围

- 移除占据输入框的大型工作方式弹层，恢复浏览器、深度检索、模型强度、多 Agent、插件、画布、电脑操作、运行记录和资料范围的直接按钮。
- “自动”按钮直接循环检索工作方式；窄聊天区域只收起文字、保留图标，不把常用能力变成不可发现的二级页面。
- 资料范围继续使用当前账号的私有资料接口和多选弹层，并保持在输入框可视边界内；选择结果随当前 Chat 请求进入服务端。

### 工作画布

- 颜色、字号和主题跟随合并为紧凑“样式”弹层，减少工具栏噪声。
- 画布继续与当前 Chat、受控浏览器事实核验、多 Agent 独立评审、编辑、版本、模板、发布、插入和查找联动。
- Agent 返回文本不会直接覆盖成果；修改和评审仍需经过当前对话与用户确认。

## 明确限制

- 本版没有伪造 Codex 插件市场，也没有宣称任何第三方 OAuth 已配置；没有安装并经管理员信任的外部插件会保持真实空态。
- `/api/runtime/capabilities` 的可用状态只证明当前服务的路由、开关和工具注册满足契约，不等于外部网站、模型账号或真实设备操作已经成功。
- Windows Authenticode、真实公网多设备、对称 NAT、自有 TURN 和 24 小时稳定性仍需对应发布环境验收；本地测试不能替代这些结论。
